## 1. 总体结论

这 10 篇论文形成了一个比较清晰的研究脉络：

1. **Time-MMD/MM-TSFlib 建立 benchmark 和基础 late-fusion 基线**，但其文本通常经过池化后再与数值分支融合。
2. **按时间保留文本结构**成为主流改进方向，代表方法包括 TAC-Time、GLoR-Forecast 和 SpecTF。
3. **无约束文本融合不稳定**。CFA、GLoR-Forecast、PA-RNet 和 LEARN-TS 都通过门控、低秩、残差修正或选择性路由控制文本注入。
4. **仅靠共享预测损失可能导致文本 collapse**。REST-TS 进一步提出给文本分支设置数值分支无法直接完成的残差监督。
5. **必须通过文本置换实验验证是否真的使用语义**。Semantics or Structure 对 Time-MMD 上的文本敏感性提出了强烈警示。
6. **文本影响不是单一时间尺度**。SpecTF、VoT 和 TAC-Time 分别从频域、事件预测和趋势/周期分解角度处理这一问题。
7. 对当前 MindTS 最有价值的组合不是“继续扩大文本输入”，而是：

   ```text
   按时间编码事件文本
   + 内容/状态条件筛选
   + 受约束门控融合
   + 文本专属残差或对齐监督
   + 文本置换与 collapse 审计
   ```

## 3. `Time-MMD.pdf`

### 3.1 定位

Time-MMD 是数据集和 benchmark；MM-TSFlib 是配套的多模态时间序列预测库，而不是另一个独立数据集。

论文发表于 NeurIPS 2024 的 Datasets and Benchmarks track。数据覆盖 9 个领域：Agriculture、Climate、Economy、Energy、Environment、Health、Security、Social Good 和 Traffic。数值序列包含 daily、weekly、monthly 等不同频率，文本来自报告、网页搜索和领域资料。

### 3.2 数据构建设计

数据构建分为三步：

1. **数值序列构建**：选择可靠、持续更新、具有实际意义的政府或领域数据源，确定目标变量并清理缺失值。
2. **文本序列构建**：人工选择报告源和搜索关键词，抓取文本，用 LLM 过滤无关内容、区分事实与预测，并生成摘要。
3. **数值—文本对齐**：使用二值时间戳标记文本的起止时间，使文本覆盖区间能够与不同频率的数值序列匹配。

论文强调三点：多领域、细粒度对齐、减少数据污染。它还指出文本具有稀疏、噪声大和有效持续时间不确定等特点。

### 3.3 MM-TSFlib 基础结构

官方框架将两种模态分别建模：

```text
数值输入 X ──> TS backbone ──> 数值表示/预测

文本序列 S ──> 冻结 LLM ──> pooling ──> projection ──> 文本表示/预测

两条分支 ──> 可学习线性融合 ──> 最终预测
```

主要设计：

- 冻结 BERT、GPT-2、Llama 等语言模型，只训练投影层和融合相关参数。
- 通过 pooling 处理文本长度不一致，支持 `avg`、`min`、`max` 和 attention 等方式。
- 通过统一接口把文本编码器接到 20 多个数值预测 backbone 上。
- 采用 MSE 作为主要预测指标，覆盖多种预测长度。

### 3.4 论文报告的现象

原论文在 9 个领域、多个 backbone 和预测长度上进行了大规模实验，报告多模态版本在绝大多数设置优于数值版本，平均 MSE 降幅超过 15%，文本丰富领域最高约 40%。论文还观察到：文本数量、领域性质、预测 horizon 会影响收益；更大的 LLM 并不必然带来更好的时序预测表现。

### 3.5 对当前 MindTS 的启发与风险

Time-MMD 的数据构建强调时间对齐，但 MM-TSFlib 的基础融合仍容易把文本压成窗口级表示。由此产生两个重要风险：

- 新闻的具体发生日期和影响持续时间可能在 pooling 后被抹平。
- 共享预测损失可能让数值分支承担主要任务，文本分支只学习一个稳定偏置。

因此，Time-MMD 适合用于验证你的改进，但不能把原论文的平均收益直接当作文本语义收益；必须配套文本删除、常量文本、同域打乱和跨域打乱实验。

## 4. `Spectral Text Fusion.pdf`

论文：**Spectral Text Fusion: A Frequency-Aware Approach to Multimodal Time-Series Forecasting**。PDF 标注为 AISTATS 2026 Proceedings。

### 4.1 解决的问题

文本对时间序列的影响可能跨越多个时间尺度：政策或宏观叙事影响长期趋势，突发事件影响短期变化，季节性或周期性因素又有另一种频率结构。直接在时间域逐步拼接文本，难以显式表达“哪一类文本影响哪一个频段”。

### 4.2 模型结构

SpecTF 的流程为：

```text
X_history ──rFFT──> 频域数值表示 ─────────────┐
                                                ├─> FreqCMF ─> 频域预测 ─> irFFT
文本 S ──LLM+时间嵌入+复数投影──> 复数文本表示 ──┘
```

具体模块：

1. **数值频域嵌入**：对历史序列做 `rFFT`，用 FreqMLP 映射频率分量，并加入频率位置编码。
2. **文本嵌入**：冻结 BERT 或 GPT-2 得到文本表示，加入 timestamp embedding，再通过两个 MLP 分别得到复数表示的实部和虚部。
3. **Frequency Cross-Modality Fusion**：以频域数值表示生成 query，以文本频域表示生成 key/value，计算每个频率分量对应的文本注意力。
4. **复数乘法融合**：

   ```text
   X_fuse = X_emb ⊙ O
   ```

   复数乘法同时调节幅度和相位，因此文本既可以改变某个频段的强弱，也可以改变其时间对齐关系。
5. **频域预测和逆变换**：在频域用 FreqMLP 预测未来频率分量，再通过 `irFFT` 得到时域预测。

### 4.3 实验与消融

论文在 Time-MMD 和另一个多模态 benchmark 上评测，报告 SpecTF 在多数 Time-MMD 领域优于 TaTS、MM-TSF、TimeXer、FreTS、Time-LLM 和 ChatTime。它还报告了较低的参数量、MACs 和推理时间。

关键消融结论：

- 去掉复数乘法融合会明显退化。
- 用直接相加替代频率交叉注意力会退化，尤其在 Agriculture 上更明显。
- 实部/虚部分开使用普通 MLP 不如联合复数建模。
- 去掉文本后多个领域性能下降，说明该模型的文本路径确实参与了预测；但这仍不等价于完成严格的文本内容置换审计。

### 4.4 对 MindTS 的启发

SpecTF 不直接解决新闻“是哪一天发生”的问题，而是解决文本影响的时间尺度问题。对 MindTS 可借鉴为：

- 每天新闻先编码成事件向量；
- patch 内得到局部文本序列；
- 对事件文本或跨模态残差做趋势/高频分解；
- 让新闻分别影响趋势重构、短期波动重构或异常事件重构。

需要注意，直接把 MindTS 全部模块改成复数频域模型会显著增加改造复杂度。更稳妥的第一步是保留时域主干，仅在文本门控或异常分数中加入低频/高频分解。

## 5. `UNLOCKING THE VALUE OF TEXT.pdf`

论文：**Unlocking the Value of Text: Event-Driven Reasoning and Multi-Level Alignment for Time Series Forecasting**，ICLR 2026。

### 5.1 核心观点

该论文把文本的作用分成两部分：

- 外生文本描述现实世界事件，适合驱动突发变化或结构转折。
- 数值序列和由数值统计量生成的内生文本，适合描述自身趋势和季节性。

因此模型不是简单把两种文本拼在一起，而是建立事件预测分支和数值预测/对齐分支。

### 5.2 Event-driven Reasoning

事件分支采用三步生成流程：

1. 根据数据集描述和样本生成数据集专属模板。
2. 用模板从原始外生文本中提取、过滤并总结与预测相关的事件信息。
3. 将摘要、数值历史和提示词送入 Reasoner，生成事件驱动预测和推理过程。

为了降低 LLM 推理不稳定性，论文提出 Historical In-context Learning：

```text
训练阶段：生成事件预测 → 与真实值比较 → 生成纠错解释 → 存入知识库
推理阶段：当前摘要 embedding → 检索相似历史样本 → 将纠错解释放入 prompt
```

知识库保存摘要 embedding 和对应的纠错过程，而不仅仅保存最终预测值。

### 5.3 Multi-level Alignment

**表示层 ETA**：

- 对时间序列表示和内生文本分别提取 trend、seasonal 两类特征。
- 用可学习 query 从文本表示中提取趋势和季节语义。
- 用 cross-attention 将时序表示与对应文本成分对齐。
- 对趋势对和季节对分别使用双向对比损失。

**预测层 AFF**：

- 对数值分支预测和事件分支预测分别做 FFT。
- 将频谱分成 low、mid、high 三个频段。
- 每个频段学习数值分支和事件分支的融合权重。
- 经过逆 FFT 得到最终预测。

总损失包括数值分支预测损失、对齐损失和最终融合预测损失。

### 5.4 实验结论

论文在 10 个数据集上实验，其中 9 个来自 MM-TSFlib benchmark。VoT 在与时序-only、文本增强和其他多模态方法比较时取得较强结果。消融显示，去掉 ETA、HIC 或事件分支都会退化；事件文本相对于随机文本和仅由数值统计生成的文本更有效。

### 5.5 对 MindTS 的启发

最值得借鉴的不是直接把 Reasoner 接到 MindTS，而是职责分离：

- 外生新闻负责事件和残差；
- 内生时序表示负责正常模式、趋势和季节性；
- 融合时按频段或事件类型决定权重。

这与 MindTS 的“文本一致性异常评分”很契合：异常不一定是重构误差大，也可能是观测到的数值变化与新闻事件解释不一致。

## 6. `Rethinking.pdf`

论文：**Rethinking Multimodal Fusion for Time Series Forecasting: Text Modalities Need Constrained Fusion**，PDF 标注为 KDD ’26 MILETS Workshop。

### 6.1 研究问题

论文对多种时序 backbone、文本模型、数据集和融合位置进行大规模比较，结论是简单 addition 和 concatenation 经常低于数值-only baseline。原因是文本是辅助模态，可能包含与当前时序无关、冲突或重复的信息；无约束融合会破坏已经学好的数值表示。

### 6.2 受约束融合基线

论文比较了三类通用受约束方法：

1. **Gating**：

   ```text
   z_fused = z_TS + g_t ⊙ z_text
   ```

   gate 决定当前时间步需要注入多少文本。
2. **FiLM**：用文本生成 scale 和 bias，对数值表示进行调制，而不是直接覆盖。
3. **Orthogonal fusion**：只注入文本投影到数值空间后与数值表示正交的成分，尽量保留数值结构。

### 6.3 Controlled Fusion Adapter

CFA 是论文的主要模块：

```text
z_adapter = W_down z_text
z_adapter = ReLU(LayerNorm(z_adapter))
z_text_controlled = W_up z_adapter
z_fused = z_TS + z_text_controlled
```

其中 `W_down` 和 `W_up` 构成低秩瓶颈，论文实验中使用约为原维度八分之一的瓶颈比例，并将 `W_up` 初始化为接近零，使训练初期主要保留数值 backbone 的行为。

低秩限制的作用不是提升文本表达能力，而是过滤无关文本并限制文本对数值主干的破坏范围。论文还在 informative、contradicting 和 irrelevant text 条件下分析，低秩瓶颈对误导性文本的抑制最明显。

### 6.4 实验与局限

论文报告了超过 20K 组设置，覆盖 9 个多模态数据集、14 个时序 backbone、4 个文本模型、4 个预测 horizon 和多种融合策略。受约束融合整体更稳定，CFA 通常优于直接 addition/concatenation。

论文的结果支持 MindTS 使用门控，但也提出一个限制：门控本身仍可能学成常数 gate。因此 MindTS 需要同时监控 gate 分布，并用文本置换验证 gate 是否响应内容，而不能只看最终异常检测指标。

## 7. `GLoR-forecast.pdf`

论文：**GLoR-forecast: State-Contingent Global-Local Text Routing for Financial and Socio-Economic Time-Series Forecasting**。Scientific Reports Article in Press，DOI 为 `10.1038/s41598-026-67974-0`。

### 7.1 核心区分

GLoR-Forecast 将文本分为：

- **local text**：与某个 timestamp 对齐的局部事件信息。
- **global text**：整个 lookback window 的宏观背景或主导叙事。

它并没有完全放弃全局文本，而是同时保留局部和全局两条信息路径。

### 7.2 模型结构

1. 冻结 PLM 编码每个时间戳的文本，并对 token embedding 做平均池化。
2. 共享 projection 将每个时间戳的文本映射成局部文本变量 `l_t`。
3. 对整个窗口的文本 embedding 计算可学习 relevance score，用 softmax 得到权重，形成全局向量 `g`，再投影为 `γ`。
4. 以当前数值观测 `x_t` 作为 router query：

   ```text
   q_t = W_q ψ(x_t)
   k_local = W_l l_t
   k_global = W_g γ
   r_t = softmax([q_tᵀ k_local, q_tᵀ k_global] / τ)
   z_t = r_local l_t + r_global γ
   ```

5. 将 `[x_t; z_t]` 输入 iTransformer 等数值预测 backbone。

缺失文本使用固定空文本占位符，router 学习降低这类文本的权重。

### 7.3 实验结论

论文在 9 个 Time-MMD 领域上比较 Uni-modal、MM-TSFlib、TaTS 和 GLoR-Forecast。相对于 TaTS，论文报告平均 MSE 降低 5.8%、MAE 降低 4.7%，Economy、Social Good、Traffic 和 Agriculture 收益较明显。

去掉 router、改为把 local 和 global 文本静态拼接后投影，9 个领域的 MSE 都变差，平均相对退化约 3.5%。这直接支持“同一条新闻在不同数值状态下不应拥有固定权重”。

### 7.4 重要局限

- 主实验主要固定 iTransformer，跨 backbone 验证仍不充分。
- 主比较是单次训练，缺少多随机种子和显著性检验。
- router temperature 的敏感性分析留作未来工作。
- local 文本仍然是每个 timestamp 一个 pooled vector，并没有做到新闻条目级筛选。

### 7.5 对 MindTS 的启发

这是与当前改造方向最直接的工作之一。MindTS 可以使用类似的三路结构：

```text
当天新闻/事件向量       → local event
窗口内多日新闻聚合       → global context
当前 patch 的时序状态    → router query
```

但 MindTS 比 GLoR-Forecast 还需要进一步解决 patch 级异常检测、新闻影响延迟和对齐分数校准问题。

## 8. `Does Text Actually Help.pdf`

论文：**Does Text Actually Help? Uncovering and Resolving Text Collapse in Multimodal Time Series Forecasting**，arXiv:2606.19413v1。

### 8.1 Text collapse 诊断

论文定义 **text collapse**：不同文本输入经过文本分支后几乎得到相同表示，文本分支与输入内容无关，因而不能提供有区分度的语义信号。

作者使用有效秩等指标检查文本分支表示的多样性，发现 MM-TSFlib 和 TaTS 在多个 backbone、多个 Time-MMD 领域上都出现低有效秩。论文的解释是：

- 数值历史与预测目标存在强自相关；
- 数值 backbone 能够以更低代价降低共享预测损失；
- 文本是辅助模态，在梯度竞争中被压制；
- 如果没有文本专属任务，优化器会选择数值 shortcut。

### 8.2 REST-TS 设计

REST-TS 为数值和文本分支分配互补职责。

**数值分支**：在线 backbone 产生联合预测；另维护一个由 EMA 更新的 target network，产生不带文本的稳定预测 `Y_ts`。

```text
R = Y - Y_ts
```

这个残差代表数值分支没有解释的部分。

**Trend–Noise–Event 分解**：

```text
R_trend = MovingAverage(R)
R_noise = TopKFFT(R - R_trend, K)
R_event = R - R_trend - R_noise
```

文本分支由冻结语言模型、可训练 projection、TrendHead 和 EventHead 组成，只负责预测 `R_trend` 和 `R_event`，不监督 `R_noise`。

**训练目标**：

```text
L = L_joint + λ1 MSE(R̂_text,trend, stopgrad(R_trend))
                + λ2 MSE(R̂_text,event, stopgrad(R_event))
```

文本头的目标使用 stop-gradient，防止数值分支通过反向传播直接吸收这两个专属任务。推理时只保留联合预测，残差头不增加推理成本。

### 8.3 实验结论

REST-TS 在 Time-MMD 的多种 backbone-domain 组合上大多数优于 Uni-modal、MM-TSFlib 和 TaTS。论文同时报告文本有效秩、文本与目标的 CKA、文本/数值梯度比和预测对文本扰动的 divergence；REST-TS 的文本表示多样性和文本敏感性更高。

需要谨慎解读的是：REST-TS 的收益在不同领域、不同 backbone 上并不完全一致；它依赖残差分解中“趋势/事件可由文本解释、噪声不可由文本解释”的假设。这个假设在 MindTS 的异常检测任务上需要用正常验证集和异常类型分析重新校准。

### 8.4 对 MindTS 的启发

这是解释当前外生文本收益不稳定的最关键论文之一。MindTS 可以增加不参与最终推理的训练辅助头：

- 文本 patch 表示预测局部重构残差的平滑部分；
- 文本 patch 表示预测异常事件残差；
- 无新闻日期不强行施加事件监督；
- 记录 text effective rank、特征方差、文本/时序梯度比和置换后的预测变化。

这比单纯增加压缩器容量更可能从根本上阻止文本分支退化成平均背景向量。

## 9. `Semantics or Structure.pdf`

论文：**Semantics or Structure? Auditing Text Sensitivity in Multimodal Time-Series Forecasting**，ICML 2026 Workshop。

### 9.1 审计问题

常见实验是比较“有文本”和“关闭文本”的 MSE，但这个比较不能证明模型使用了文本语义。文本分支可能输出一个与内容无关的固定向量，也可能携带与文本一起输入的数值列；两种情况都会产生表面上的 multimodal lift。

### 9.2 置换协议

论文固定模型和所有数值输入，只替换文本内容：

1. 原始文本。
2. 空文本。
3. 所有样本使用同一常量占位文本。
4. 同一领域内随机打乱文本。
5. 跨领域随机替换文本。
6. Oracle 文本：用模板描述未来真实值，作为文本路径是否能响应数字语义的必要性测试。

论文还检查梯度、注意力熵、预测变化以及 Time-MMD 中可能与文本共同输入的数值列。

### 9.3 主要结论

在其测试的 MM-TSFLIB、TaTS 和 AURORA 上，替换文本内容带来的平均 MSE 变化小于 0.5%。论文认为已发表的多模态提升在部分架构中主要来自与文本路径共同输入的 numeric prior，而不是新闻语义。

对于 AURORA，文本路径的梯度不为零，但不同文本条件下注意力熵几乎不变，说明路径被训练过却仍可能在前向传播中对内容不敏感。

### 9.4 对当前 MindTS 的必要实验

MindTS 至少应加入下列诊断：

| 实验 | 主要回答的问题 |
|---|---|
| 关闭外生文本 | 文本路径总体是否有用 |
| 空文本/常量文本 | 是否只是使用固定偏置 |
| 同域打乱日期 | 是否利用了时间对应关系 |
| 跨域打乱文本 | 是否利用了领域语义 |
| 只保留日期、不保留文本内容 | 时间位置本身是否造成收益 |
| 删除可能共同输入的数值列 | 是否存在 numeric prior 混淆 |
| 文本有效秩、方差、CKA | 是否发生 text collapse |
| 正常点/异常点的置换敏感度 | 文本是否真正改变异常排序 |

这篇论文不是一个可直接移植的融合模块，而是当前研究路线的实验可信度底线。

## 10. `TAC-Time.pdf`

论文：**TAC-Time: Texts as Channels For Multimodal Time Series Forecasting**，arXiv:2609.24156v1。

### 10.1 核心观点

TAC-Time 不把文本当成静态辅助向量，而是把每个时间点的文本特征转换成额外的时间通道，与数值通道一起进入时序 backbone：

```text
每个 timestamp 的文本
    → 文本特征提取器
    → 文本通道
    → 与数值通道拼接
    → 统一时序模型
```

这与用户提出的“每天一个向量、按 patch 组织”在思想上非常接近。

### 10.2 主要模块

1. **Textual Channel Extractor**：冻结 GPT 生成 token 表示，再将文本特征映射到与数值通道兼容的维度。
2. **Sparse Autoencoder**：将高维文本 embedding 压缩为稀疏语义因子，损失为重构损失加 L1 稀疏项。
3. **Orthogonality regularization**：鼓励不同文本通道之间去相关或近似正交，减少多个通道表达同一信息。
4. **Frequency decomposition**：对文本和数值通道共同做 FFT，使用相对频率截断将信号分为 trend 和 season 两部分。
5. **Forecasting**：将分解后的多通道表示送入 iTransformer 风格的 inverse embedding/通道建模模块，并联合优化预测、SAE 和正交损失。

### 10.3 关键诊断和结果

论文进行三类特别有价值的分析：

- **文本打乱实验**：将文本重新分配到其他时间戳后性能下降，支持时间对齐确实重要。
- **频域分析**：比较文本和数值通道的频谱相关性，发现频谱更一致的领域通常文本收益更明显。
- **滞后对齐分析**：计算文本通道和数值通道的 cross-correlation，在存在领先/滞后关系时对文本进行时间偏移；Security 实验中报告了偏移后的收益。

论文的消融显示，去掉 SAE、频域分解、正交约束或冻结 GPT 都会退化；同时报告 TAC-Time 的显存和参数开销高于简单数值模型，但仍低于部分 LLM forecasting 方法。

### 10.4 对 MindTS 的启发

TAC-Time 给出一个比“窗口文本压成一个向量”更自然的实现形式：

- `text_daily[t]` 是一个时间通道，而不是窗口级广播向量；
- patch embedding 可以同时聚合数值 patch 和对应文本 patch；
- 新闻影响可能存在 delay，应测试 `t-1`、`t-2` 或可学习滞后；
- 用频谱相关性判断哪些数据域更可能从文本中获益。

但不能直接照搬所有模块。MindTS 的异常检测重点是重构和异常排序，文本通道应通过 patch masking 和局部重构来接入，而不是只追求预测 MSE。

## 11. `PA-RNet.pdf`

论文：**PA-RNet: Perturbation-Aware Residual Network for Robust Multimodal Time Series Forecasting**，arXiv:2508.04750v2，PDF 标注修订于 2026-05-10。

### 11.1 解决的问题

文本不只有“有用/无用”两种状态，还可能包含插入的无关短语、词序扰动、反义词、截断和数值泛化错误。直接融合原始文本 embedding 会把不稳定语义传给预测器。

PA-RNet 的目标是：在文本受到扰动时，保留稳定的上下文信息，压制扰动相关成分。

### 11.2 模型结构

PA-RNet 包含三块：

1. **数值 perturbation-aware projection**：从数值输入中估计扰动相关分量，用自适应 gate 控制其贡献，再从原数值表示中扣除或抑制这部分。
2. **文本 spectral residual correction**：将文本序列 embedding 投到频域，使用 LoRA 风格低秩变换和 cosine mask 估计不稳定的谱残差，再通过 IFFT 得到修正后的文本序列。
3. **Cross-modal attention**：数值表示作为 query，修正后的文本表示作为 key/value，只提取与当前 temporal dynamics 相关的文本成分。

整体可以概括为：

```text
数值扰动抑制
      + 文本谱残差修正
      → 跨模态注意力对齐
      → 预测
```

### 11.3 理论与实验

论文证明模型相对于文本 embedding 具有 Lipschitz 连续性，使文本扰动引起的输出变化受到控制；在零均值文本扰动假设下，谱残差修正可以降低期望预测误差。

实验在多个文本-数值 benchmark 上比较 Uni-modal、MM-TSFlib、TaTS 和 PA-RNet，并对文本注入、打乱、反义替换、截断等扰动强度进行测试。论文报告 PA-RNet 在原始文本和扰动文本下都保持较稳定的表现，平均排名优于对比方法。消融显示，去掉跨模态注意力、谱残差修正或数值扰动模块都会退化。

### 11.4 对 MindTS 的启发

PA-RNet 更适合解决“文本噪声和错位”而非“文本是否真正被使用”。MindTS 可以吸收两点：

- 用文本扰动一致性作为训练或验证指标，检查模型是否对无关词、截断和日期错位过度敏感。
- 在文本压缩器后增加低秩残差修正或稳定性正则，抑制新闻编码的随机噪声。

不过，PA-RNet 的谱残差修正和理论假设较重，建议在完成按天对齐和文本置换审计之后再加入。

## 12. `LEARN-TS.pdf`

论文：**LEARN-TS: LLM-Enhanced Alignment and Reconstruction with Normality Guidance for Multivariate Time-Series Anomaly Detection**，arXiv:2609.38789v1。

### 12.1 与 Time-MMD 的关系

LEARN-TS 不是 Time-MMD 外生新闻预测论文。它不要求为每个监控窗口准备真实外部文本，而是从数值窗口生成 observation prompt，并使用一个固定、数据集无关的 normality prompt。因此它属于 MindTS 的邻近异常检测工作，而不是 MM-TSFlib benchmark 复现。

### 12.2 双语义表示

1. **Observation representation**：从完整数值窗口提取趋势、波动、跨变量关系等描述，但不暴露精确数值、异常标签、变化点位置或明确异常判断。
2. **Normality representation**：由固定的 dataset-agnostic prompt 得到，表达时间连续性、相关变量协同变化、合理状态转移和恢复能力等正常性概念。

语言模型冻结，两个文本表示通过共享 projection 映射到时序模型空间，并可离线缓存。

### 12.3 Patch-masked 重构和门控融合

训练时把所有变量同一时间区间的 patch 一起 mask，阻止模型直接复制该时间点的数值。时序 patch 表示作为 query，对 observation text 做 cross-attention，然后使用门控残差：

```text
G = sigmoid(MLP([U; A]))
V = G ⊙ A + (1 - G) ⊙ U
U_next = TransformerBlock(V)
```

也就是说，文本不是无条件相加，而是由当前 patch 表示决定注入比例。这是与 MindTS 门控融合最直接的异常检测类参考。

### 12.4 正常性对齐与异常分数

训练目标包含：

```text
L = L_mask + λ_full L_full + λ_norm L_norm
```

其中 `L_norm` 让正常训练窗口的融合表示接近固定 normality embedding。

推理时：

1. 逐个 mask temporal patch，得到该 patch 的重构证据 `r_t`。
2. 用完整未 mask 窗口计算与 normality embedding 的 cosine discrepancy `d_t`。
3. 在正常验证集上分别校准两个分数。
4. 用正常性差异调制重构分数：

   ```text
   S_t = r_z,t [1 + λ_gate ReLU(d_z,t)]
   ```

### 12.5 实验和启发

LEARN-TS 在 SWaT、SMD、PSM、MSL 四个异常检测 benchmark 上测试，在 16 个数据集-指标组合中取得 13 个最高平均结果。消融支持 observation conditioning、门控融合、正常性对齐和正常性调制的作用，但论文也显示语义参考带来的增益具有数据集依赖性。

对 MindTS 的启发：

- 外生新闻可作为 observation/event context；
- 可以建立正常事件或正常跨模态对齐参考；
- patch 级 mask 比窗口级重构更适合定位异常；
- 对齐差异应作为重构分数的条件调制，而不是无条件相加。

| 问题 | 代表论文 | 解决机制 | 对 MindTS 的优先级 |
|---|---|---|---|
| 文本被压成窗口级向量，丢失时间位置 | Time-MMD 基线暴露的问题、GLoR、TAC-Time | 每时间步/时间戳文本通道、局部-全局分离 | 最高 |

## 14. 对当前 MindTS 改造的建议顺序

### 阶段 A：先做诊断，不改主模型

1. 对现有 MindTS 做空文本、常量文本、同域打乱、跨域打乱和日期错位实验。
2. 记录文本分支的有效秩、batch 内方差、不同新闻输入的 cosine distance。
3. 记录文本/数值梯度范数比和文本对异常分数排序的影响。
4. 检查是否存在和文本路径共同输入的数值列或重构偏置。

如果这些实验显示文本置换几乎不改变输出，就应优先解决 text collapse，而不是先堆叠更复杂的 cross-attention。

### 阶段 B：按日期缓存文本表示

建议的数据结构：

```text
date[t]
news_embedding[t, d]
news_valid[t]
news_count[t]
```

每天多条新闻可以先在日期内做 attention pooling 或 top-k 选择；没有新闻的日期使用 `no_news_embedding`，同时保留 `news_valid=0`，不要仅依靠一个特殊向量让模型自行猜测。

### 阶段 C：按 patch 形成文本序列

对每个时序 patch，将对应日期的新闻表示组织成：

```text
text_patch[p] = Pool(news_embedding[t_start:t_end])
```

同时保留日期 mask、新闻数量和相对位置。建议先实现局部 patch pooling，再比较：

- local-only；
- local + window-global；
- local + global + state router。

### 阶段 D：加入受约束融合

推荐从低复杂度版本开始：

```text
g_p = sigmoid(MLP([ts_patch_p; text_patch_p; news_valid_p]))
fused_p = ts_patch_p + g_p ⊙ LowRank(text_patch_p)
```

需要记录 gate 的均值、方差、正常/异常差异、有新闻/无新闻差异，防止 gate 退化成常数。

### 阶段 E：增加文本专属监督

在不改变推理路径的情况下，增加辅助头预测：

- 时序-only 重构与真实值之间的平滑残差；
- 突发/尖峰残差；
- 当前 patch 与新闻的对齐标签或弱对齐分数。

可参考 REST-TS 的 stop-gradient 残差监督，但异常检测中应使用训练正常数据和伪异常验证其稳定性。

### 阶段 F：最后再加入跨模态异常评分

先单独报告：

```text
reconstruction_score
alignment_score
gate_value
```

再在正常验证集上归一化和校准，最后测试：

```text
final_score = α * reconstruction_score
            + β * alignment_score
```

不要一开始把对齐分数直接加到重构误差上，否则新闻缺失、发布时间延迟和领域不相关文本都可能制造伪异常。

## 15. 最终判断

当前 MindTS 的文本压缩设计可以作为轻量的 baseline，但不是一个充分利用外生文本的结构。它的主要缺陷不单是“压缩太狠”，而是：

1. 压缩前缺少按日期的事件分组；
2. 压缩后缺少 patch 级时间定位；
3. 融合缺少对无关文本的显式约束；
4. 共享重构目标没有强迫文本分支学习内容；
5. 没有用文本置换实验证明异常排序依赖语义。

因此最有说服力的改进路线是：

```text
按天/事件编码
→ patch 级时间对齐
→ local-global 或事件筛选
→ 低秩门控融合
→ 文本专属残差监督
→ 文本敏感性审计
→ 校准后的跨模态异常评分
```

这条路线同时吸收了 GLoR-Forecast、TAC-Time、Rethinking、REST-TS、LEARN-TS 和 Semantics or Structure 的关键思想，并且与当前 MindTS 的异常检测目标保持一致。
