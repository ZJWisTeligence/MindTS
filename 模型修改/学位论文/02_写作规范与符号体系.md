# 写作规范与符号体系

更新时间：2026-10-12
状态：全文术语、符号与报告规则的统一依据

## 1. 总主线与章节模板

主线沿用 [论文总纲](01_论文总纲与章节安排.md)：SAGE 建模内部结构和预测证据的样本级融合，TETRA 建模外部事件条件下的正常重构残差。

第三、四章采用一致的叙述顺序：

~~~text
研究动机 → 问题定义 → 总体流程 → 核心模块
        → 训练与评分 → 实验设置 → 结果与机制分析 → 小结
~~~

正文按“输入是什么—输出是什么—如何使用—为什么需要”介绍模块。两章编号可因模块数量而不同，不为形式一致强行增加标题。

### 1.1 叙述风格约束

正文采用直接、具体、以论证为中心的写法。每一段只承担一个主要任务，优先说明结论，再解释原因，最后给出必要的例子或证据。

- **结论前置。** 先说明本段要建立的判断，再解释机制和实验依据；不先罗列条件、风险或可能的反对意见。
- **删除无效开场。** 删除不增加事实、判断或证据的套话，例如“值得注意的是”“需要指出的是”等。
- **使用具体条件。** 说明方法对什么输入、什么场景、什么证据有效，以及具体改善了什么；避免使用“在一定程度上”“可能具有积极影响”等空泛表达。
- **只回应真实问题。** 只有在前文确实存在歧义或实验确实显示边界时，才补充限定、反例或适用范围。
- **保持单段单事。** 优势、原因、局限、前景和建议分开处理；一个段落同时承担多个任务时拆分段落。
- **集中放置边界。** 必要的假设、适用范围和局限放在引起误解的位置或专门的局限段落，不在每个段落重复防御性说明。

推荐的基本顺序为：

```text
核心判断 → 形成原因 → 具体证据或例子 → 必要边界
```

该规则适用于绪论、方法、实验分析、结论和摘要。方法章节重点写清“输入—处理—输出—作用”，实验章节重点写清“结果—原因—证据”，不为制造审慎语气而预设读者尚未提出的质疑。

## 2. 统一术语

| 概念 | 统一术语与解释 |
|---|---|
| 总任务 | 时序异常检测 |
| 序列自身信息 | 内部时序证据 |
| 新闻等外部输入 | 外生文本；一般叙述使用“外部事件证据” |
| 趋势、局部变化、窗口结构和预测误差 | 内部异常证据 |
| 随上下文变化的正常预期 | 条件正常性；首次解释为“上下文感知正常模式” |
| 每条文本分别编码 | 事件级文本表示 |
| 按当前检测时刻判断文本是否可用 | 时间可用性 |
| 事件与数值时间片的关系 | 时间可用性对齐 |
| SAGE 的误差 | 预测残差 |
| TETRA 数值分支的误差 | 正常重构残差 |
| TETRA 条件头的输出 | 事件条件残差均值与不确定性 |
| 观测残差偏离条件预期 | 事件残差不一致 |
| SAGE 融合机制 | 样本级自适应门控 |
| 推理输出 | 最终异常分数 |

SAGE 是同一数值来源的多视图/多证据方法；TETRA 引入数值—文本模态。新闻记录是否存在与事件是否实际发生是不同问题。时间可用性用于控制未来信息，不表述为“因果对齐”或因果效应识别。

## 3. 符号总约束

- 大写通常表示序列、窗口或矩阵；T、L、P、N 分别作为序列长度、窗口长度、目标 patch 长度和正常训练窗口数。小写表示观测、向量、索引或分数；集合使用花体。
- 同一个完整符号只表示一种含义。不同用途通过明确的上标或下标区分。
- 全文用小写 s 表示异常分数；用 \(\mathcal L\) 表示训练损失。
- t 为数值时刻/窗口末端，p 为目标 patch，i 为文本记录，j 为数值变量，b 为结构视图；\(\ell\) 为目标 patch 内的位置，\(\star\) 只作明确列出的分支标签占位。
- \(\varepsilon\) 只表示数值稳定项；权重用 \(\lambda\) 并按用途添加下标。
- 公式、架构图、图注、表注和记录字段使用同一套符号。

### 3.1 共同输入与任务符号

| 符号 | 含义 |
|---|---|
| \(X=\{x_1,\ldots,x_T\}\) | 完整数值序列 |
| \(x_t\in\mathbb R^d\) | 时刻 t 的 d 维观测 |
| \(X_t=x_{t-L+1:t}\) | 长度为 L、末端为 t 的窗口 |
| \(\mathcal D_N\) | 正常训练窗口集合 |
| \(N=\lvert\mathcal D_N\rvert\) | 正常训练窗口数 |
| \(y_t\in\{0,1\}\) | 时刻 t 的评价标签，1 表示异常；不作为正常性分支的训练输入 |
| \(p\) | TETRA 目标 patch 索引 |
| \(P,\ell,t_p\) | 目标 patch 长度、其内部位置、其末端数值时刻 |
| \(x_p\in\mathbb R^{P\times d}\) | 目标 patch 内的观测矩阵，\(x_{p,P,j}\) 是末端的第 j 个变量 |
| \(X_p^{\mathrm{mask}}\) | 含固定遮蔽目标 patch 的数值上下文 |

### 3.2 SAGE 符号

| 符号 | 含义 |
|---|---|
| \(X_t^{\mathrm{tr}},X_t^{\mathrm{res}}\) | 趋势窗口与去趋势残差窗口 |
| \(f_{t,j}^b,c_b,R_b\) | 变量级结构特征、视图级固定正常中心、软边界欧氏半径 |
| \(\nu\) | 软边界比例；半径按正常训练距离的 \(1-\nu\) 分位数更新 |
| \(\hat x_t\) | 根据前 L−1 个观测得到的末端预测 |
| \(r_t^{\mathrm{pred}}=x_t-\hat x_t\) | 预测残差 |
| \(s_t^{\mathrm{str}},s_t^{\mathrm{pred}}\) | 校准前的结构分数和预测分数 |
| \(\tilde s_t^{\mathrm{str}},\tilde s_t^{\mathrm{pred}}\) | 分别完成 robust scaling 的两类分数 |
| \(z_t^{\mathrm{str}},z_t^{\mathrm{pred}}\) | 分支角色交换的七维门控输入 |
| \(h_{\mathrm{gate}},b_0\) | 共享门控 MLP 与全局校准项 |
| \(g_t\in[0,1]\) | 预测证据的融合权重 |
| \(s_t^{\mathrm{SAGE}}\) | SAGE 最终异常分数 |
| \(k_{\mathrm{top}}\) | 多变量高分子集聚合的固定大小 |
| \(a_t^{\mathrm{str}},a_t^{\mathrm{pred}}\) | 伪异常相对正常窗口的正向、尺度调整后的分支响应 |
| \(\tilde g_t,\omega_t\) | 预测证据权重的软监督目标、二元熵形成的置信度 |
| \(\tau_{\mathrm{gate}},\gamma\) | 相对敏感度目标的温度、正常—伪异常排序间隔 |

核心融合式：

\[
s_t^{\mathrm{SAGE}}
=(1-g_t)\tilde s_t^{\mathrm{str}}+g_t\tilde s_t^{\mathrm{pred}}.
\]

g 较大表示更依赖预测证据，全文不反转这一约定。

结构分数先在每个变量内累加趋势与残差的平方距离，再用 \(\operatorname{TopMean}_{k_{\mathrm{top}}}\) 取高分变量均值；预测分数对变量平方误差使用同一算子。中心在结构训练前初始化后固定，半径用于训练目标，不进入推理分数的分母。

### 3.3 TETRA 符号

| 符号 | 含义 |
|---|---|
| \(a_i,\tau_i^{\mathrm{pub}}\) | 文本记录与首次公开发布时间 |
| \(\tau_p^{\mathrm{start}},\tau_p^{\mathrm{end}}\) | 当前数值上下文起点、目标 patch 检测末端；start 不指仅目标 patch 的起点 |
| \(h_i,e_i\) | 冻结编码器的池化语义向量、投影后的事件向量 |
| \(\mathcal A_p\) | 当前上下文中、检测时刻前已发布的文本集合 |
| \(h_p\) | 数值编码器在重构投影层前的窗口表示 |
| \(\alpha_{pi},u_p\) | 事件聚合权重、聚合后的事件表示 |
| \(e_{\varnothing}\) | 无可用文本时的可学习表示 |
| \(\hat x_p\) | 目标 patch 的正常重构 |
| \(r_p^{\mathrm{rec}}=x_p-\hat x_p\) | 固定掩码正常重构残差 |
| \(\mu_p,\sigma_p\in\mathbb R^{P\times d}\) | 条件残差均值、正的不确定性尺度 |
| \(v_p\) | 条件头输出的尺度参数，经逐元素 Softplus 与稳定项形成 \(\sigma_p\) |
| \(q_p\) | 由文本数量与时间距离形成的可用性/质量权重 |
| \(s_p^{\mathrm{num}},s_p^{\mathrm{event}}\) | 校准前的数值分数和事件残差不一致分数 |
| \(s_p^{\mathrm{TETRA}}\) | TETRA 最终异常分数 |
| \(\Delta t_{pi},\tau\) | 事件时间距离、聚合与 q 共用的时间衰减尺度 |
| \(d_a\) | 注意力内积维度，区别于数值变量数 d |
| \(n_{\mathrm{ref}}\) | 正常训练窗口正事件数量的中位数 |

SAGE 的预测残差与 TETRA 的重构残差始终保留 pred/rec 上标。q 表示可观察的文本可用性，\(\sigma\) 表示条件预测的不确定性，两者不能互相替代。主模型的 e 由语义向量投影得到，不默认包含人工事件属性。

TETRA 的训练损失对全部目标 patch 位置与变量求均值；主评价分数仅使用末端位置 P，对变量求均值。两个模型都以步长 1 形成末端点级分数，并与该时刻的标签对应，不向较早位置广播分数。

## 4. 公式简洁性与章节边界

正文保留解释方法主线所需的公式：输入/分解、证据分数、门控、时间可用性、条件残差、训练目标和最终评分。一个公式承担一个主要作用，首次出现的符号立即说明。

逐层矩阵、每种替代成像算子的展开、扰动采样参数和缓存细节放在实现说明、实验设置或附录。七维输入与阶段训练目标需要能追溯，但不为它们重复建立多套字母。

| 章节 | 应写内容 | 留到后文的内容 |
|---|---|---|
| 第二章 | 通用任务、正常性概念、文本异步性、融合思想、共同符号和评价原则 | 两个模型的完整结构、专属损失和具体实验 |
| 第三章 | 结构与预测证据、门控、两阶段训练和内部证据实验 | 外部文本与事件条件头 |
| 第四章 | 固定正常重构、事件表示、时间聚合、条件残差和一致性评分 | 新增推理器、复杂路由、频域或检索模块 |
| 第五章 | 已得研究认识、适用范围、局限和未来工作 | 新方法或新的完整研究现状 |

方法章的问题定义仅实例化本章任务，不重复第二章全文。TETRA 使用“正常重构”，SAGE 使用“短期预测”，二者不互换。

## 5. 分数校准与统计量来源

| 事项 | 当前统一来源 |
|---|---|
| 输入归一化、SAGE 中位数/IQR、结构中心与半径 | 正常训练数据 |
| TETRA 数值分数校准 | 全部正常训练窗口 |
| TETRA 事件分数校准与正事件数量参考值 | 有可用事件的正常训练窗口 |
| 早停、模型配置、固定融合权重、TETRA 融合系数 | 验证集，采用预先声明的选择规则 |
| 最终评价 | 测试集；不参与统计量拟合或调参 |

两章都以对应分支正常训练分数的中位数 \(m_\star\) 和四分位距 \(\operatorname{IQR}_\star=Q_{0.75}-Q_{0.25}\) 为校准依据，统计量在分支训练结束后冻结。

SAGE 使用带符号的 robust scaling，供门控比较分支相对响应。TETRA 的 \(\operatorname{Norm}_\star(s)=\max(0,(s-m_\star)/(\operatorname{IQR}_\star+\varepsilon))\) 使用非负上偏差，供数值与事件证据相加。两者共享统计来源，保留各自已声明的输出规则；同一实验组的所有融合对照采用相同校准。

TETRA 在最终融合式中分别校准数值与事件分数，不重复校准同一分数。融合系数非负、验证候选包含 0，无新闻时严格回到相同校准的数值-only 分数。

异方差高斯训练损失包含对数方差项，推理中的标准化残差分数不包含完整该项，因此不将推理分数直接称为完整条件负对数似然。

## 6. 统一实验报告规则

- 按时间划分并记录训练、验证和测试范围；模型训练使用正常训练窗口。
- 当前主要随机种子固定为 2021、4396，同一实验组使用相同种子。
- 主结果和核心消融直接报告均值±标准差；逐 seed 明细保留在附录或实验记录中。
- 不另设独立的“多随机种子稳定性”研究模块；两个或五个种子的扩展需同步全部主表与核心消融。
- 指标采用 AUC-PR、AUC-ROC、VUS-PR、VUS-ROC 和 PA-F1，并保留各数据集结果。
- 阈值、后处理、点调整规则及指标实现版本一次性说明；不以测试标签选择模型超参数。
- 同组比较保持数据、窗口、变量聚合、评价和资源统计口径一致。
- 报告参数量、训练/推理时间和显存峰值，记录设备、代码版本及配置。
- 数据来源、基准预处理、异常标签及真实发布时间来源分别记录。

### 6.1 SAGE 的机制证据

核心对照为单分支、固定平均、验证集固定权重与自适应门控。补充门控输入、归一化、伪异常、趋势—残差分解和异常形态分析。固定融合与门控复用同一组已冻结的分支输出。

### 6.2 TETRA 的机制证据

核心对照为数值-only、真实/零/随机/置换文本、时间置换、未来屏蔽、窗口/事件级表示、直接融合/条件残差、固定/可学习方差及有/无新闻分组。

同时报告正常残差方差、条件预测误差、文本有效率、特征方差/有效秩、q 与 \(\sigma\) 分布、数值/事件分数相关性及增量收益。各项详细设置以第四章方案为准。

## 7. 贡献表述与机制解释

方法贡献围绕“内部证据的自适应选择”和“外部条件下的正常残差一致性”。具体编码器、普通注意力、投影层、工程缓存或单数据集提升不单独包装为主要贡献。

正式贡献段落维护在两章方案的第 1 节，总纲 1.4 采用相同版本。SAGE 通过相对敏感度监督学习融合关系；TETRA 通过事件条件残差目标实现跨模态联系，不必须增加单独的对比学习模块。

TETRA 的非负事件项补充不一致性证据，不直接扣除数值误差。因此叙述强调条件判断与异常区分，不将当前评分机制写成自动压低事件可解释变化的数值异常分数。

可以解释证据互补、时间组织和条件残差的作用。门控或注意力变化反映模型响应，不能直接证明事件导致异常或揭示异常真实原因。文本的增量作用通过内容和时间对照说明。

两项模型使用不同数值分支时，按预测证据与固定重构目标的职责解释。图表每项结论都对应实际实验，文献中的预测收益不作为本文检测收益。
