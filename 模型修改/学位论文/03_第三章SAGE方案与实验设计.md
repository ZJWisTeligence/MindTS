更新时间：2026-10-11

## 1. 本章定位与已定配置

SAGE（Sample-wise Adaptive Gated Evidence）研究数值序列内部结构证据与预测残差证据的样本级自适应融合。本章只使用内部数值信息，外部文本及事件条件残差留到第四章。

核心问题：

> 结构形态异常和短期预测异常并不总是同时出现，如何根据当前样本状态选择更可靠的证据？

**正式贡献表述：**针对不同异常形态下内部数值证据的响应差异，本文提出样本级自适应门控证据模型 SAGE。该模型通过趋势—残差结构表示和短期预测残差构建互补证据，结合分数校准与共享门控实现样本级证据选择，并利用正常样本的局部扰动构造相对敏感度监督，在不依赖真实异常训练标签的条件下学习融合关系。

贡献重点是互补证据的组织、样本级门控和伪异常驱动的融合学习。GASF、ViT、Deep SVDD 和 iTransformer 是采用的基础组件，各自引用原始文献；检测收益及机制作用分别由主结果和对照实验说明。

| 部分 | 已定主配置 |
|---|---|
| 趋势—残差分解 | 全序列单侧因果移动平均后对齐切窗 |
| 结构表示 | 趋势与残差分别转换为 GASF |
| 结构编码 | 两个独立 ViT；行 token、class token、固定正弦位置编码与全输出 token 平均 |
| 正常性目标 | Deep SVDD 软边界目标；训练前初始化并固定中心，每轮以正常训练距离更新半径 |
| 预测分支 | iTransformer，用窗口前 L−1 个观测预测末端观测 |
| 多变量处理 | 变量级结构转换与固定高分变量子集聚合；预测平方误差采用同一聚合规则 |
| 分数校准 | 正常训练分数的中位数与四分位距，保存到 checkpoint |
| 门控 | 七维输入、分支角色交换的共享 MLP、全局校准项 |
| 门控方向 | g 表示预测证据权重 |
| 门控训练 | 冻结证据分支；六类伪异常与相对敏感度目标；置信度加权 BCE 和排序损失 |
| 主报告 | 2021、4396 两个种子的均值±标准差与逐 seed 记录 |

CNN 为预测骨干对照，DE、MTF、STFT 为结构表示对照，对称移动平均为非因果敏感性设置。主配置沿用已定设计，不因合并文档新增模块。

## 3. 核心公式与模块职责

统一符号见 [全文规范](02_写作规范与符号体系.md)。

### 3.1 输入与因果分解

\[
X_t=x_{t-L+1:t},\qquad
X^{\mathrm{tr}}=\mathcal D_k^{\mathrm{causal}}(X),\qquad
X^{\mathrm{res}}=X-X^{\mathrm{tr}}.
\]

先对完整序列做单侧分解，再按相同索引提取原始、趋势和残差窗口。时刻 t 的分解只使用不晚于 t 的样本。核宽 k 与边界处理列入实验配置。

### 3.2 结构表示与正常性

趋势和残差视图各自成像与编码。对变量 j：

\[
f_{t,j}^b=\phi_b\bigl(\operatorname{GASF}(X_{t,j}^b)\bigr),
\qquad b\in\{\mathrm{tr},\mathrm{res}\}.
\]

同一视图的编码器在变量间共享，两个视图的编码器不共享。令 \(N=|\mathcal D_N|\)，正常中心在结构训练前用初始编码器的正常训练特征估计，此后固定：

\[
c_b=\frac{1}{Nd}
\sum_{t\in\mathcal D_N}\sum_{j=1}^{d}f_{t,j}^b.
\]

每个视图采用软边界一类目标：

\[
\mathcal L_{\mathrm{occ}}^b
=R_b^2+\frac{1}{\nu Nd}
\sum_{t\in\mathcal D_N}\sum_{j=1}^{d}
\max\left(0,\|f_{t,j}^b-c_b\|_2^2-R_b^2\right),
\qquad
\mathcal L_{\mathrm{str}}
=\mathcal L_{\mathrm{occ}}^{\mathrm{tr}}
+\mathcal L_{\mathrm{occ}}^{\mathrm{res}}.
\]

\(R_b\) 是欧氏距离半径，\(\nu\in(0,1]\) 控制软边界比例。每轮训练后，用正常训练特征到中心的欧氏距离的 \(1-\nu\) 分位数更新半径；恢复阶段一 checkpoint 时一并恢复对应中心和半径。

推理使用两个视图的平方距离之和，再聚合变量：

\[
s_{t,j}^{\mathrm{str}}
=\|f_{t,j}^{\mathrm{tr}}-c_{\mathrm{tr}}\|_2^2
+\|f_{t,j}^{\mathrm{res}}-c_{\mathrm{res}}\|_2^2,
\qquad
s_t^{\mathrm{str}}
=\operatorname{TopMean}_{k_{\mathrm{top}}}
\bigl(s_{t,1}^{\mathrm{str}},\ldots,s_{t,d}^{\mathrm{str}}\bigr).
\]

\(\operatorname{TopMean}_{k_{\mathrm{top}}}\) 表示取向量中最大的 \(k_{\mathrm{top}}\) 个元素求平均，\(1\leq k_{\mathrm{top}}\leq d\)，单变量时为 1。先在同一变量内合并趋势与残差，再选择高分变量；预测分支使用同一个聚合算子，但分别选择本分支的高分变量。

平方距离不除以半径，也不减去半径平方；半径用于一类训练目标，分支间尺度在后续校准。该定义已按技术资料 PDF 印刷页 28、公式（3.15）—（3.18）核对。多变量预测分支采用相同 top-k 规则是当前方案的统一聚合约定，参考 PDF 的多变量预测评分使用全变量均值。

### 3.3 预测证据

\[
\hat x_t=f_{\mathrm{iTrans}}(x_{t-L+1:t-1}),
\qquad
r_t^{\mathrm{pred}}=x_t-\hat x_t.
\]

预测证据由变量级平方误差按既定规则聚合：

\[
s_t^{\mathrm{pred}}=
\operatorname{TopMean}_{k_{\mathrm{top}}}
\left((r_{t,1}^{\mathrm{pred}})^2,\ldots,
(r_{t,d}^{\mathrm{pred}})^2\right).
\]

预测分支在正常训练窗口上最小化全变量平均平方误差：

\[
\mathcal L_{\mathrm{pred}}
=\frac{1}{Nd}\sum_{t\in\mathcal D_N}
\sum_{j=1}^{d}(r_{t,j}^{\mathrm{pred}})^2.
\]

训练对全部变量求均值，检测时采用 top-k 聚合，二者职责不同。预测输入不含目标末端观测，改变骨干不改变预测目标、残差定义或评分协议。预测证据只刻画数值自身的动态偏离。

### 3.4 分数校准

\[
\tilde s_t^{\,\star}
=\frac{s_t^\star-m_\star}{\operatorname{IQR}_\star+\varepsilon},
\qquad \star\in\{\mathrm{str},\mathrm{pred}\}.
\]

\(m_\star\) 和 \(\operatorname{IQR}_\star\) 分别为正常训练分数的中位数和四分位距。两个分支独立校准，统计量冻结并保存。这里保留带符号的校准分数，不截断低于中位数的部分。

### 3.5 七维输入与对称共享门控

令

\[
d_t=\tilde s_t^{\mathrm{str}}-\tilde s_t^{\mathrm{pred}},
\qquad c_t=[c_{1,t},c_{2,t},c_{3,t}],
\]

\[
c_{1,t}=\operatorname{mean}|X_t-\operatorname{mean}_{\mathrm{time}}(X_t)|,\quad
c_{2,t}=\max|X_t-\operatorname{mean}_{\mathrm{time}}(X_t)|,\quad
c_{3,t}=\operatorname{std}(X_t).
\]

前两项先对每个变量沿时间维去均值，再对窗口全部条目取均值或最大值；第三项对窗口全部条目计算总体标准差。这三个上下文统计量基于采用正常训练统计量预处理后的数值窗口。

两种分支角色的输入为：

\[
z_t^{\mathrm{str}}
=[\tilde s_t^{\mathrm{str}},\tilde s_t^{\mathrm{pred}},d_t,|d_t|,c_t],
\]

\[
z_t^{\mathrm{pred}}
=[\tilde s_t^{\mathrm{pred}},\tilde s_t^{\mathrm{str}},-d_t,|d_t|,c_t].
\]

c 是三个标量，故总输入为七维。两个输入经过同一个 \(h_{\mathrm{gate}}\)：

\[
o_t^{\mathrm{str}}=h_{\mathrm{gate}}(z_t^{\mathrm{str}})-b_0/2,
\qquad
o_t^{\mathrm{pred}}=h_{\mathrm{gate}}(z_t^{\mathrm{pred}})+b_0/2,
\]

\[
g_t=\operatorname{Softmax}
(o_t^{\mathrm{str}},o_t^{\mathrm{pred}})_{\mathrm{pred}}.
\]

g 较大时更依赖预测证据，较小时更依赖结构证据。

### 3.6 融合与两阶段训练

\[
s_t^{\mathrm{SAGE}}
=(1-g_t)\tilde s_t^{\mathrm{str}}+g_t\tilde s_t^{\mathrm{pred}}.
\]

阶段一训练两个结构编码器与预测分支，目标概括为：

\[
\mathcal L_{\mathrm{base}}
=\mathcal L_{\mathrm{str}}
+\lambda_{\mathrm{pred}}\mathcal L_{\mathrm{pred}}.
\]

恢复验证规则选定的阶段一 checkpoint，计算并保存正常训练分数统计量。阶段二冻结证据分支、中心/半径和校准统计量，只更新共享门控与 \(b_0\)。

阶段二使用正常窗口及其伪异常版本。记扰动窗口为 \(X_{t,+}=\mathcal A(X_t)\)，下标 + 在分数与门控中保持相同含义。两分支的正向相对响应为：

\[
a_t^\star
=\frac{\max(0,\tilde s_{t,+}^{\,\star}-\tilde s_t^{\,\star})}
{|\tilde s_t^{\,\star}|+1+\varepsilon},
\qquad \star\in\{\mathrm{str},\mathrm{pred}\}.
\]

伪异常门控的软目标取预测分支的相对响应权重：

\[
\tilde g_t=
\operatorname{Softmax}
\left(\frac{a_t^{\mathrm{str}}}{\tau_{\mathrm{gate}}},
\frac{a_t^{\mathrm{pred}}}{\tau_{\mathrm{gate}}}\right)_{\mathrm{pred}},
\qquad
\omega_t=1-\frac{H_2(\tilde g_t)}{\log 2}.
\]

其中 \(H_2(v)=-v\log v-(1-v)\log(1-v)\) 为二元熵，约定 \(0\log0=0\)。\(\tau_{\mathrm{gate}}>0\) 为门控目标温度。响应差异越明确，监督权重越高；两分支均无正向增量时软目标为 0.5，熵权重为零。

门控训练目标为：

\[
\mathcal L_{\mathrm{gate}}
=\frac{\sum_t\omega_t\operatorname{BCE}(g_{t,+},\tilde g_t)}
{\sum_t\omega_t+\varepsilon},
\qquad
\mathcal L_{\mathrm{rank}}
=\operatorname{mean}_t
\max(0,\gamma-s_{t,+}^{\mathrm{SAGE}}+s_t^{\mathrm{SAGE}}),
\]

\[
\mathcal L_{\mathrm{stage2}}
=\lambda_{\mathrm{gate}}\mathcal L_{\mathrm{gate}}
+\lambda_{\mathrm{rank}}\mathcal L_{\mathrm{rank}}.
\]

BCE 的第一个参数为预测权重、第二个为软监督目标；\(s_{t,+}^{\mathrm{SAGE}}\) 使用扰动窗口自己的 \(g_{t,+}\)。以上求和和均值只遍历实际施加扰动的样本对，未扰动的窗口不产生伪异常排序监督。目标与置信度均由冻结分支计算，不参与反向更新。

这些定义对应技术资料印刷页 31—32、公式（3.29）—（3.37），已将软目标方向统一为预测证据权重，并给置信度归一化分母加入稳定项。阶段损失分别报告，不把两阶段解释为同时联合更新。

六类伪异常为：spike injection、local level shift、local trend drift、local amplitude modulation、local phase shift、contextual segment mixing。原始与扰动窗口经过同样的分解、成像、编码、预测、校准与门控流程。

伪异常分解沿用单侧滤波，并保留原窗口左侧的正常历史上下文。扰动概率、位置、长度、幅度、温度 \(\tau_{\mathrm{gate}}\)、排序间隔 \(\gamma\) 及损失权重写入实验配置或附录，具体数值按实验记录填写。

### 3.7 推理与导出

~~~text
数值窗口 → 结构/预测分支 → 分数校准 → 七维门控 → 最终分数
~~~

保存两类原始与校准分数、g、最终分数和时间索引，供固定融合对照、门控分布和误报漏报案例分析使用。

窗口分数只映射到其末端时刻 t，以步长 1 滑动形成点级评分，并与 \(y_t\) 对应。不把分数广播给窗口内较早时刻；序列开头不足 L 的位置按统一规则从所有方法的可比较评价范围排除。

**正文公式安排：**3.4 保留分解、结构分数和一类目标，3.5 保留预测残差与误差分数，3.6 保留七维输入、门控与融合，3.7 保留两阶段目标及相对敏感度监督。中心初始化、半径更新、二元熵/BCE 的标准展开及六类扰动采样细节放在紧邻的实现说明或附录，不为每个中间步骤单独编号。

## 4. 实验计划与结果分析

### P0：必须完成

| 编号 | 实验 | 对照设置 | 需要验证的结论 |
|---|---|---|---|
| E1 | 融合机制对照 | 结构分支、预测分支、固定平均、验证集固定权重、自适应门控 | 自适应门控是否优于固定融合 |
| E2 | 分支互补性 | 结构分支、预测分支、完整融合 | 两类证据是否互补 |
| E3 | 多随机种子 | 当前主数据集与主设置使用 2021、4396；如协议升级则统一扩展到五个种子 | 主结论是否稳定 |

E1 是最重要的新增实验。缺少固定融合对照时，只能证明联合使用两个分支有效，不能充分证明样本级门控有效。

### 4.1 公平比较要求

- 同组实验使用相同数据、窗口、训练资源、种子和评价脚本。
- 固定平均、验证集固定权重与自适应门控复用同一组阶段一输出与校准统计量。
- 验证集用于早停和超参数/固定融合权重选择；分数统计量从正常训练数据估计。
- 所有主表与核心消融使用 2021、4396，并直接报告均值±标准差。
- 评价指标、阈值、后处理和资源统计按全文规范。
- 每组记录唯一变量、固定变量和所支撑的结论。

### 4.2 结果解释

总体效果、分支互补、门控独立收益分别论证。联合模型优于单分支只说明证据组合有价值；固定融合与门控对照用于说明样本级选择的增量。

异常形态分析以分数曲线、门控分布和案例解释模型响应。GASF/iTransformer 的替代配置检验实现依赖，不自动作为新的主要贡献。

## 6. 实验—结论对应关系

| 论文结论 | 必要实验 | 主要证据 |
|---|---|---|
| 内部数值证据具有异质性 | 结构分支与预测分支单独结果 | 两类分支在不同数据集或异常形态上表现差异 |
| 结构证据和预测证据具有互补性 | 单分支、固定融合和门控融合消融 | 联合模型相较单分支更加稳定 |
| 自适应门控优于固定融合 | 单分支、固定融合与自适应门控比较 | 自适应门控在多个数据集或异常类型上稳定改善 |
| 门控输入具有实际作用 | 门控输入消融 | 完整输入优于仅分数输入 |
| 分数校准有助于证据融合 | 分数归一化消融 | 合理归一化减少分支尺度差异的影响 |
| 伪异常训练能够提供门控信号 | 伪异常训练消融 | 多种合理扰动带来更稳定的门控学习 |
| 趋势—残差分解有助于结构建模 | 完整分解与去除分解消融 | 结构分数和总体指标发生可解释变化 |
| 门控具有一定可解释性 | 门控分布、分数曲线和典型案例 | 门控与证据主导关系保持一致 |
| 方法具有跨数据集稳健性 | 多数据集、多随机种子主表 | 均值提升且标准差处于可接受范围 |
