## 1. 本章定位与正式结构

TETRA（Temporal Exogenous Text–Residual Alignment）研究外部事件条件下的数值正常性。数值分支形成稳定的正常重构残差，事件分支估计该残差在已观测事件条件下的正常均值与不确定性，实际残差偏离条件预期时提供辅助异常证据。

核心问题：

> 当前数值变化是否符合已观测外部事件所对应的正常响应？

**正式贡献表述：**针对外部事件文本异步、稀疏且难以直接参与正常性判断的问题，本文提出时序外生文本残差对齐模型 TETRA。该模型按首次公开发布时间组织事件级语义表示，在固定数值正常重构的基础上学习事件条件下的残差均值与不确定性，并将观测残差偏离条件预期的程度转化为辅助异常证据，实现内部数值正常性与外部事件条件的联合判断。

贡献重点是时间可用的事件组织、稳定目标下的条件残差建模，以及可用性加权的不一致性评分。文本编码器与普通注意力是基础组件；“对齐”体现为事件时间组织和残差目标监督，不另设必须的跨模态对比损失。

## 2. 主模型协议与核心公式

### 2.1 固定末端 patch 正常重构

每个窗口的末端 patch 作为重构目标，在输入中完整遮蔽。训练和推理使用同一固定掩码，数值骨干为 iTransformer 的重构适配，目标 patch 真值只作为学习/评分目标。

令目标 patch 长度为 P，\(x_p,\hat x_p,r_p^{\mathrm{rec}}\in\mathbb R^{P\times d}\)，\(\ell=1,\ldots,P\) 为其内部位置，\(t_p\) 为末端数值时刻。当前上下文长度为 L，满足 \(1\leq P<L\)。

\[
\hat x_p=f_{\mathrm{num}}(X_p^{\mathrm{mask}}),
\qquad r_p^{\mathrm{rec}}=x_p-\hat x_p.
\]

数值分支用正常训练窗口的全部目标位置训练，令 \(N=|\mathcal D_N|\)：

\[
\mathcal L_{\mathrm{num}}
=\frac{1}{NPd}
\sum_{p\in\mathcal D_N}\sum_{\ell=1}^{P}\sum_{j=1}^{d}
(r_{p,\ell,j}^{\mathrm{rec}})^2.
\]

主评价采用末端点级评分，数值证据为目标 patch 最后一行的全变量平均平方误差：

\[
s_p^{\mathrm{num}}
=\frac{1}{d}\sum_{j=1}^{d}(r_{p,P,j}^{\mathrm{rec}})^2.
\]

完整 patch 的重构用于训练，末端误差用于当前检测；校准统一放到最终融合式，不再在原始数值分数中重复写 Norm。

这属于窗口内已观测但被遮蔽目标的正常重构，不使用未来观测。\(h_p\) 取遮蔽输入经过数值编码器后的、重构投影层前的窗口表示。数值分支先在正常数据上训练，条件残差训练阶段冻结其参数与掩码协议。输入归一化和隐藏表示也不读取目标 patch 真值。

### 2.2 事件集合与时间可用性

时间戳按元数据解析后统一为 UTC。令 \(\tau_p^{\mathrm{start}}\) 为当前数值上下文起点，\(\tau_p^{\mathrm{end}}\) 为目标 patch 末端：

\[
\mathcal A_p=
\{a_i\mid
\tau_p^{\mathrm{start}}\leq\tau_i^{\mathrm{pub}}
\leq\tau_p^{\mathrm{end}}\}.
\]

上式的 start 指完整当前上下文起点，不将主模型限制为仅目标 patch 内的新闻。

同一末端时间戳的文本视为可用；编辑、补录或延迟记录采用首次公开发布时间。窗口外的旧事件不进入主模型，检测末端之后发布的事件被屏蔽。发布时间字段与文本描述覆盖区间分别核对。

每个窗口在 \(t_p\) 产生一个分数，与点级标签 \(y_{t_p}\) 对应。默认以步长 1 移动末端 patch；分数不广播到 patch 内较早时刻。末端可用事件可以支持当前检测，但不能据此声称对更早位置已经作出了实时判断。不足 L 的序列起始位置在同组方法中统一排除。

### 2.3 事件级表示

\[
h_i=\operatorname{MeanPool}_{\mathrm{valid}}
(\operatorname{Enc}_{\mathrm{text}}(a_i)),
\qquad e_i=\phi_{\mathrm{event}}(h_i).
\]

编码器冻结，对有效 token 平均池化，再由轻量可训练投影得到事件向量。主模型不依赖人工事件类型、方向、强度或主体标注。发布时间服务时间对齐，文本数量和时间距离服务质量权重。

离线缓存冻结编码器输出 \(h_i\)，训练时再通过可训练投影产生 \(e_i\)，不将尚在更新的投影结果视为永久缓存。

### 2.4 时间感知聚合

\[
\alpha_{pi}
=\operatorname{Softmax}_{i\in\mathcal A_p}
\left(
\frac{(W_qh_p)^\top(W_ke_i)}{\sqrt{d_a}}
-\frac{\Delta t_{pi}}{\tau}
\right),
\]

\[
u_p=\sum_{i\in\mathcal A_p}\alpha_{pi}e_i.
\]

\(\Delta t_{pi}\) 为检测末端与发布时间的非负距离，\(d_a\) 为注意力维度，\(\tau\) 为时间衰减尺度。使用当前上下文全部可用事件；工程长度超限时按发布时间保留最近记录，不利用标签筛选。

没有可用事件时直接定义 \(u_p=e_{\varnothing}\)。该向量可学习，但最终质量权重为零。

### 2.5 条件残差分布与训练目标

\[
(\mu_p,\sigma_p)=g_{\mathrm{event}}(u_p,h_p),
\qquad \sigma_p=\operatorname{Softplus}(v_p)+\varepsilon.
\]

\(\mu_p,\sigma_p,v_p\in\mathbb R^{P\times d}\)，Softplus 逐元素作用；条件头的输入仅为事件聚合表示和遮蔽数值表示，不输入真实重构残差。残差只作为训练目标和推理评分对象。

条件头采用对角高斯工作分布，在正常窗口上学习稳定残差的条件均值和正的尺度。负对数似然省略与参数无关的常数：

\[
\mathcal L_{\mathrm{cond}}
=\frac{1}{NPd}
\sum_{p\in\mathcal D_N}\sum_{\ell=1}^{P}\sum_{j=1}^{d}
\left[
\frac{(r_{p,\ell,j}^{\mathrm{rec}}-\mu_{p,\ell,j})^2}
{2\sigma_{p,\ell,j}^2}
+\log\sigma_{p,\ell,j}
\right].
\]

训练对全部目标位置和变量求均值，不采用 top-k；SAGE 的 top-k 是内部证据聚合规则，不自动迁移为 TETRA 的训练目标。无事件正常窗口仍可用无事件表示参加条件头训练，最终检测按 q=0 退化。均值-only、固定方差作为消融，不改变主模型定义。

### 2.6 文本可用性/质量权重

有可用事件时：

\[
q_p=
\min\left(1,\frac{|\mathcal A_p|}{n_{\mathrm{ref}}}\right)
\exp\left(-\frac{\min_{i\in\mathcal A_p}\Delta t_{pi}}{\tau}\right).
\]

无可用事件时直接定义 \(q_p=0\)。参考数量确定为正常训练窗口正事件数量的中位数：

\[
n_{\mathrm{ref}}
=\operatorname{median}
\left\{|\mathcal A_p|\mid
p\in\mathcal D_N,\ |\mathcal A_p|>0\right\}.
\]

q 与时间聚合共用衰减尺度 \(\tau\)。参考数量按数据集和划分计算后保存，不由测试文本密度重新估计。

这里的“质量”由数量和新近性代理，不等同于人工评定的事件真实性、语义正确性或抽取置信度。

### 2.7 不一致性与最终评分

\[
s_p^{\mathrm{event}}
=\frac{1}{d}\sum_{j=1}^{d}
\frac{(r_{p,P,j}^{\mathrm{rec}}-\mu_{p,P,j})^2}
{\sigma_{p,P,j}^2+\varepsilon}.
\]

事件分数与数值分数使用同一末端位置和全变量均值。主配置采用非负的稳健上偏差校准：

\[
\operatorname{Norm}_\star(s)
=\max\left(0,\frac{s-m_\star}
{\operatorname{IQR}_\star+\varepsilon}\right),
\qquad \star\in\{\mathrm{num},\mathrm{event}\},
\]

\[
s_p^{\mathrm{TETRA}}
=\operatorname{Norm}_{\mathrm{num}}(s_p^{\mathrm{num}})
+\lambda q_p\operatorname{Norm}_{\mathrm{event}}(s_p^{\mathrm{event}}).
\]

数值分数的中位数与 IQR 从全部正常训练窗口估计；事件分数的对应统计量只从有可用事件的正常训练窗口估计。所有统计量在两个训练阶段结束后计算并冻结；\(\lambda\geq0\) 从预先声明的有限候选集由验证集选择，候选集包含 0。无新闻时 q=0，最终分数严格退化为同样校准的数值-only 分数。

非负校准使事件项仅提供额外的不一致性证据。事件可解释的变化具有较小的事件项；该加法设计不直接扣除数值分数，也不保证消除数值分支已经产生的误报。贡献表述使用“补充条件判断、改善异常区分”，不将其写成自动消除事件可解释异常。

事件分数是标准化残差不一致性，不包含完整高斯 NLL 的对数方差项。高斯损失用于训练分布，检测分数用于比较偏差，两者分别命名。

上述末端评分、全变量均值、正事件数量中位数与非负校准是本轮补齐的写作协议。它们确定公式含义，不表示已有实验输出已经采用该口径；正式结果与相应协议核对后填入。

**正文公式安排：**4.3 用架构图与简短文字建立整体关系，不引入新公式；4.4 保留固定重构与数值分数，4.5 保留事件编码，4.6 保留可用事件集合与时间聚合，4.7 保留条件均值/尺度，4.8 保留不一致性与最终评分，4.9 保留分阶段损失。正文训练式可用元素均值记法；完整 \(N,P,d\) 展开、参考数量统计和时间索引映射在实现说明中集中交代。

## 3. 训练、推理与审计

训练顺序：

1. 在正常窗口上训练数值固定掩码重构分支。
2. 选定并冻结数值参数与掩码，形成稳定重构残差目标。
3. 冻结文本编码器，按训练/验证/测试划分缓存语义输出。
4. 训练事件投影、时间聚合与条件残差头。
5. 保存正常训练校准统计量，验证集选择已声明的融合配置。

推理导出数值与事件的原始/校准分数、最终分数、q、\(\mu\)、\(\sigma\)、事件可用集合、目标位置和对应末端时间索引。点级评价只使用末端输出，完整 patch 的残差与条件输出作为机制分析材料保留。

正常残差审计包括均值、方差、有/无新闻差异，以及无文本条件头与事件条件头的误差。分数审计包括数值/事件相关性、单独使用、融合及增量收益。数值分支残差过小或事件分数重复数值分数时，需要据审计解释，而非只看整体指标。

缓存记录首次公开时间、时区、划分、编码器版本和有效 token 处理，防止未来文本与跨划分信息混入。

## 4. 实验计划与结果分析

| 实验组 | 主要对照 | 对应问题 |
|---|---|---|
| 文本有效性 | 数值-only、真实、零、随机、文本置换、仅文本元信息 | 使用了文本内容还是仅使用存在性/密度？ |
| 时间可用性 | 真实发布时间、时间置换、无时间偏置、严格未来屏蔽 | 正确时间组织是否有效？ |
| 表示粒度 | 窗口级、事件级、加入时间偏置和质量权重 | 事件粒度的增量来自哪里？ |
| 条件残差 | 数值-only、直接文本融合、条件均值、条件均值与方差 | 正常残差建模是否优于直接融合？ |
| 不确定性 | 均值-only、固定方差、可学习方差 | 不确定性是否有独立作用？ |
| 覆盖率 | 有/无新闻、不同密度和质量代理分组 | 稀疏场景的退化与辅助作用是否合理？ |
| 可学习性与增量 | 残差方差、无文本/文本条件误差、分数相关性与融合 | 文本条件是否提供独立于数值历史的信息？ |

每组控制冻结数值主干、数据、窗口、种子和评价口径。主结果及核心消融使用 2021、4396 的均值±标准差，逐 seed 明细保存在记录/附录。文本替换实验记录替换对象、样本对应关系与时间字段处理，区分语义置换与时间置换。

## 6. 实验—结论对应关系

| 结论 | 必要证据 |
|---|---|
| 外部文本提供增量信息 | 真实文本优于数值-only、零/随机文本，并通过内容置换审计 |
| 时间组织有作用 | 正确发布时间与时间置换、无偏置对照 |
| 输入不包含未来文本 | 时间可用性规则、缓存和严格屏蔽记录 |
| 事件粒度更适合当前任务 | 相同编码与数值分支下的窗口/事件级对照 |
| 条件残差优于直接融合 | 同一骨干和文本输入下的直接融合/残差对照 |
| 方差与质量代理有作用 | 固定/学习方差、去除 q 及分组实验 |
| 无新闻退化合理 | q=0 的数值退化验证与有/无新闻结果 |
| 条件目标具有可学习信号 | 正常残差方差、无文本和事件条件预测误差 |
| 事件分数提供额外异常证据 | 单分数、融合、相关性与新增检出案例 |

不把方差增大直接解释为“文本质量更差”，不把统计关联解释为事件真实因果作用。语义作用、时间作用和覆盖率作用分别由对应对照回答。

## 7. 章节小结与写作边界

4.12 围绕三个所得收束：事件文本需要时间可用性组织；事件条件头刻画正常重构残差分布；残差不一致性提供辅助异常证据。

全文保持固定重构与预测的区别、q 与 \(\sigma\) 的区别，以及标准化分数与高斯训练损失的区别。主模型没有人工事件属性、完整外部推理器、检索、频域融合或复杂路由；这些不在本轮整理中重新加入。
