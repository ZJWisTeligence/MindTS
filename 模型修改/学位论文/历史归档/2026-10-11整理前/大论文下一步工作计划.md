- 确定两个原创研究工作：SAGE 和 TETRA；

当前进入：

> **SAGE 补充实验、TETRA 协议审计与正式撰写准备阶段。**

## 二、第一步：整理论文证据表

先建立“论文结论—实验依据”对应关系，确保每个核心结论都有实验支撑。

| 论文结论 | 对应实验 |
|---|---|
| 内部证据具有互补性 | SAGE 结构分支与预测分支消融 |
| 门控能够选择更可靠的证据 | 固定融合与自适应门控比较 |
| 不同异常形态适合不同证据 | 分数据集、分异常形态分析 |
| 真实文本有效 | TETRA 真实文本、零文本和随机文本对照 |
| 时间对齐有效 | 真实时间对齐与时间置换对照 |
| 文本提供独立信息 | 条件残差预测误差和数值-only 对照 |

这一步用于避免出现论文结论超出实验结果的问题。

## 三、第二步：细化第三章 SAGE

第三章已经确定以下内容，当前转入补充实验：

1. SAGE 的输入和输出；
2. 结构证据分支的具体公式；
3. 预测残差分支的具体公式；
4. 自适应门控的输入、输出和训练目标；
5. SAGE 最终异常分数；
6. 训练阶段和推理阶段；
7. 每个实验对应验证的具体结论；
8. 第三章所需的架构图、流程图、主结果表和消融表；
9. 固定融合、自适应门控、门控输入和分数归一化的补充对照。

第三章的写作顺序为：

```text
研究动机
→ 问题定义
→ 总体架构
→ 结构证据分支
→ 预测残差分支
→ 自适应门控
→ 训练与评分
→ 实验验证
→ 本章结论
```

## 四、第三步：细化第四章 TETRA

在 SAGE 章节稳定后，确定 TETRA 的以下内容：

1. 新闻事件缓存格式；
2. 时间可用性集合；
3. 事件级文本表示；
4. 新闻与数值 patch 的时间对齐；
5. 条件残差预测公式；
6. 事件残差不一致分数；
7. 文本对照实验和消融实验；
8. 未来信息泄漏控制；
9. 有新闻与无新闻窗口分析；
10. TETRA 结果的论文表述；
11. 正常重构残差有效性和事件分数独立性审计。

第四章的写作顺序为：

```text
外部事件问题
→ 时间可用性假设
→ 事件级文本表示
→ 条件残差预测
→ 事件不一致评分
→ 对照实验
→ 机制分析
→ 本章结论
```

## 五、第四步：撰写第一、二、五章

方法和实验章节固定后，再撰写：

1. 第一章绪论；
2. 第二章相关研究与统一问题定义；
3. 第五章综合结论与展望；
4. 中文摘要；
5. 英文摘要和关键词。

第一、二章的正式目录已经冻结，具体采用《第一二章最终框架与评审说明》中的版本。正式写作时，第一章重点说明研究动机和研究缺口，第二章重点完成理论基础和统一问题定义，避免两章重复综述。

这样可以让绪论、摘要和总结建立在已经确定的方法和实验发现上，避免先写出无法被结果支撑的研究叙事。

## 六、近期优先任务

当前最直接的任务是：

补充实验完成后，再根据结果锁定第三章的正式结果表和结论表述。PDF 中已有的单次运行结果暂作结构和实验设计参考，不能替代新的固定融合对照与多随机种子报告。

正式撰写前的统一确认项见《正式撰写前最终确认清单》；其中 TETRA 需要优先完成固定 mask 重构协议、残差有效性和时间信息可用性审计。
