# 第三章 SAGE 参考 PDF 适配实施规范

更新时间：2026-10-10

本文档用于锁定 SAGE 对参考 PDF 实现的继承关系、适配关系和写作表述。它服务于第三章的实现与正式撰写，避免一边改代码、一边改变模型定义。

## 1. 总体原则

SAGE 采用参考 PDF 中已经验证过的双证据实现路径作为工程基础，但按照本论文的数值证据融合任务重新组织模块、符号和叙述。参考 PDF 中的结果只用于说明实现来源和设计动机，不能直接作为 SAGE 的实验结果。

SAGE 的默认实现固定为：

```text
因果趋势—残差分解
→ 趋势与残差 GASF
→ 两个独立 ViT 一类正常性分支
→ iTransformer 一步预测分支
→ 训练集 robust scaling
→ 七维样本级门控
→ 六类伪异常驱动的第二阶段门控训练
```

其中，iTransformer 替换参考 PDF 中的 CNN 预测骨干；其余模块沿用参考实现的计算逻辑，但在当前数据接口、随机种子和多变量处理方式下重新实现和验证。

## 2. 参考实现与 SAGE 适配关系

| 模块 | 参考 PDF 的实现 | SAGE 的实现与表述 |
|---|---|---|
| 趋势—残差分解 | 在窗口采样前进行移动平均分解，并保持三个视图的时间对齐 | 默认使用因果移动平均，防止被评分时刻之后的样本进入分解；对称移动平均只作为非因果敏感性实验 |
| 结构表示 | 趋势和残差分别转换为 GAF 图像 | 默认明确为 GASF；正文强调 GASF 用于保留窗口内的全局形态关系，DE、MTF、STFT 仅作替代表示 |
| 视觉编码 | 两个独立 ViT，一行一个 token，加入 class token 和固定正弦位置编码，平均全部输出 token | 保留该编码流程；两个分支参数不共享，以分别学习趋势结构和残差结构的正常模式 |
| 正常性目标 | DeepSVDD 风格软边界一类目标 | 保留目标形式，表述为“结构正常性分支”；中心和半径只由正常训练数据估计 |
| 预测分支 | 原始窗口的一步预测，参考实现使用 CNN | 改为 iTransformer；仍然使用历史窗口预测末端观测，训练目标和残差评分协议不变 |
| 分数校准 | 每个证据分支独立使用中位数和四分位距进行 robust scaling | 统计量只从训练窗口估计并保存到 checkpoint；验证集只用于选择实验配置和融合超参数 |
| 门控输入 | 两个归一化分数、分数差异、绝对差异和三个上下文统计量 | 保留七维输入；统一使用 SAGE 符号，并规定门控值表示预测证据权重 |
| 门控网络 | 分支角色交换的共享 MLP，并加入全局校准项 | 保留共享 MLP 和校准项；门控输出方向改写为预测分支权重，避免沿用参考文档中相反的符号含义 |
| 门控训练 | 冻结证据分支，使用六类伪异常和相对敏感度目标训练门控 | 保留六类扰动、置信度加权 BCE 和排序损失；扰动概率、温度和排序间隔在实验配置中显式记录 |
| 推理与评价 | 证据分数归一化后融合，最终分数再进入统一评价流程 | 使用当前 benchmark 的评分、阈值和后处理协议；参考 PDF 的单种子结果不直接复用 |

## 3. SAGE 的适配性核心

### 3.1 预测骨干适配

SAGE 的预测分支使用 iTransformer，而不是把参考 PDF 的 CNN 作为默认骨干。适配后的预测目标保持简单且可比较：给定长度为 (L) 的原始窗口，使用前 (L-1) 个观测预测末端观测。这样改变的是动态依赖建模器，不改变预测残差作为第二类数值证据的定义。

预测分支写为：

\[
\hat{x}_t=f_{\mathrm{iTrans}}(x_{t-L+1:t-1}),
\qquad
r_t^{\mathrm{pred}}=x_t-\hat{x}_t.
\]

正文中应将 iTransformer 的作用表述为“建模变量间和时间上下文中的动态依赖”，不能直接写成“更强骨干必然带来更好的异常检测结果”。是否有效由 CNN 替代实验和固定融合对照决定。

### 3.2 因果分解适配

参考实现支持对称和因果移动平均。SAGE 的正式推理协议采用因果版本：在时刻 (t) 计算趋势时，只使用不晚于 (t) 的观测。分解应在完整时间序列上先计算，再按同一时间索引切窗，确保原始、趋势和残差窗口严格对齐。

正文只需保留：

\[
X^{\mathrm{tr}}=\mathcal D_k^{\mathrm{causal}}(X),
\qquad
X^{\mathrm{res}}=X-X^{\mathrm{tr}}.
\]

移动平均核宽 (k) 属于数据集相关超参数，不能在没有实验记录时写成普适最优值。每个数据集的取值、搜索范围和是否使用边界填充都应写入实验配置。

### 3.3 多变量结构分支适配

对于单变量窗口，趋势和残差分别直接转换为 GASF。对于多变量窗口，各变量独立生成结构表示并得到变量级分数，再进行分数级聚合。默认聚合采用参考实现中的高分变量子集平均，以避免大量弱异常变量稀释局部异常。

高分变量子集的大小 (k_{\mathrm{top}}) 必须在代码配置和实验表中明确。它不能根据测试标签动态选择，也不能在不同模型之间使用不同的聚合规则。

预测分支的多变量残差先计算各变量平方误差，再用同一份固定聚合规则得到标量预测分数。结构分数和预测分数在进入门控前分别校准，保证门控输入的尺度可比。

### 3.4 门控符号适配

参考 PDF 中的门控符号与最终融合式采用了“结构分支权重”的约定。SAGE 统一规定 (g_t) 表示预测分支权重：

\[
o_t^{\mathrm{str}}=h(z_t^{\mathrm{str}})-\frac{b_0}{2},
\qquad
o_t^{\mathrm{pred}}=h(z_t^{\mathrm{pred}})+\frac{b_0}{2},
\]

\[
g_t=\operatorname{softmax}(o_t^{\mathrm{str}},o_t^{\mathrm{pred}})_{\mathrm{pred}},
\qquad
s_t^{\mathrm{SAGE}}=(1-g_t)\tilde{s}_t^{\mathrm{str}}+g_t\tilde{s}_t^{\mathrm{pred}}.
\]

这里 (h) 在两个分支角色交换后的输入上共享参数，(b_0) 是 Stage 2 学习的全局校准项。正式撰写时不得在同一章中把 (g_t) 一会儿解释为结构权重、一会儿解释为预测权重。

### 3.5 伪异常训练适配

SAGE 只用正常训练窗口生成伪异常，不使用测试标签。每个伪异常窗口从以下六类扰动中选择一种：

- spike injection；
- local level shift；
- local trend drift；
- local amplitude modulation；
- local phase shift；
- contextual segment mixing。

原始窗口和伪异常窗口必须经过完全相同的分解、GASF、ViT、iTransformer、分数归一化和门控流程。门控目标由两个分支对扰动的正向分数增量构造，并使用熵置信度加权的 BCE 与正常—伪异常排序损失。

扰动位置、长度、幅度、选择概率、温度 (	au)、排序间隔 (gamma) 和损失权重不得隐藏在代码默认值中。它们应进入统一配置，并在消融实验中区分“无伪异常”“单一扰动”和“六类扰动”。

## 4. 实现阶段的固定训练协议

### Stage 1：证据分支

联合训练两个 ViT 一类正常性分支和 iTransformer 预测分支。训练完成后恢复验证集上最优 checkpoint，并计算训练窗口的结构分数、预测分数、中位数和四分位距。

### Stage 2：门控分支

冻结 Stage 1 的三个证据分支和所有分数校准统计量，只更新共享 MLP 与 (b_0)。伪异常只从训练正常窗口构造。Stage 2 不重新拟合结构中心、半径或 iTransformer。

### Inference：统一评分

推理阶段依次得到：

```text
结构分数 → 预测分数 → robust scaling → 七维门控 → SAGE 分数
```

同时保存两个单分支分数、门控权重和最终分数，方便完成固定融合对照、门控分布分析和错误案例分析。

## 5. 论文表述的适应性规则

### 5.1 可以继承的表述

- 趋势与残差视图能够提供不同时间尺度的结构证据；
- GASF 将一维窗口映射为含有时间关系的二维结构表示；
- 一类目标适合在仅有正常训练数据时建模结构正常性；
- 预测残差对局部动态偏离提供补充证据；
- robust scaling 能够减轻不同分支分数尺度不一致的影响；
- 伪异常可以为没有异常标签的门控训练提供相对敏感度信号。

### 5.2 必须改写的表述

- 将“视觉分支”统一改写为“结构证据分支”，避免把 SAGE 写成计算机视觉模型的直接移植；
- 将“预测网络选择”改写为“动态证据提取器选择”，突出 iTransformer 只改变动态建模能力；
- 将“融合权重”改写为“样本级证据可靠性权重”，但只有在固定融合对照有效时才能使用“可靠性”这一解释；
- 将“模型在所有数据集上优于基线”改写为“模型在统一协议下表现出更稳健的跨数据集证据融合能力”；
- 将 PDF 的实验数值改写为“参考实现中的观察”，SAGE 正文只报告当前重新运行得到的多 seed 结果。

### 5.3 不应直接照搬的内容

- 参考 PDF 的模型名称、章节标题、图注和段落结构；
- 参考 PDF 的随机种子、数据集结果和平均数值；
- 参考 PDF 中把 CNN 作为默认预测骨干的结论；
- 未经重新实验验证的“门控一定优于固定融合”或“iTransformer 一定优于 CNN”；
- 仅凭门控权重推断异常原因的表述。

## 6. 当前仍需在代码运行前锁定的配置

以下项目属于实现级配置，暂不改变 SAGE 的模型故事，但必须在第一次正式实验前固定：

1. 各数据集的输入窗口长度 (L)；
2. 因果移动平均核宽 (k) 与边界处理；
3. ViT 的输入分辨率、表示维度、层数和头数；
4. iTransformer 的层数、隐藏维度、头数和 dropout；
5. 多变量高分变量子集大小 (k_{\mathrm{top}})；
6. 六类伪异常的概率、位置、长度和幅度范围；
7. (	au)、(gamma)、\(\lambda_{\mathrm{gate}}\) 和 \(\lambda_{\mathrm{rank}}\)；
8. 最终分数的后处理和 PA-F1 阈值协议；
9. 主数据集列表及 `2021`、`4396` 两个随机种子的正式报告方式。

这些参数应先采用参考 PDF 的默认范围进行小规模试跑，再用验证集或统一搜索协议确定，不能因为参考实现使用过某个设置就直接写成 SAGE 的理论结论。

## 7. 实施完成判据

SAGE 代码达到以下条件后，才进入正式第三章撰写：

- 默认配置能完整运行 Stage 1 和 Stage 2；
- iTransformer 与 CNN 共享相同输入、目标、评分和评价协议；
- 因果分解不会读取当前评分时刻之后的数据；
- 结构分数、预测分数、门控权重和最终分数均能单独导出；
- 固定平均、验证集固定权重和自适应门控可以复用同一组 Stage 1 输出；
- 两个随机种子能够输出逐 seed 结果、均值、标准差和资源消耗；
- 每个正文结论都有对应消融或敏感性实验。
