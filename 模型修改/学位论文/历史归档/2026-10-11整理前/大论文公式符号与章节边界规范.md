# 大论文公式符号与章节边界规范

## 1. 文档目的

本规范用于统一学位论文中 SAGE 与 TETRA 两个模型的公式、符号和章节职责，避免同一概念在不同章节中重复定义、改名或使用不同字母表示。后续撰写模型章节、实验章节和总结章节时，以本文件为准。

## 2. 统一叙事主线

论文围绕“多源异质证据下的时序异常检测”展开：

1. 首先利用数值序列内部的结构证据和预测残差证据，完成内部证据的样本级自适应融合。
2. 然后引入带发布时间的外部事件文本，描述外部事件条件下的正常变化。
3. 最终从数值是否偏离正常模式，以及数值变化是否与已观测事件相一致两个角度判断异常。

SAGE 负责内部证据融合，TETRA 负责外部事件条件残差建模。两者在论文中是递进关系，不能写成同一个模型的简单堆叠。

## 3. 公式和字母的总体约束

### 3.1 变量大小写

- 大写字母表示序列、窗口、矩阵或集合，例如 (X)、(X_t)、(H)、\(\mathcal A_p\)。
- 小写字母表示单个时刻、单个事件、向量、标量或分数，例如 (x_t)、(a_i)、(h_i)、(s_t)。
- 希腊字母表示权重、尺度、时间差、不确定性或超参数，例如 (\alpha)、(\tau)、(\sigma)、(\lambda)。
- 同一个字母在全文中只承担一种主要含义，模型章节之间不得重新赋予含义。

### 3.2 序列和窗口

- (X)：完整数值序列。
- (x_t)：时刻 (t) 的观测向量。
- (X_t)：以 (t) 为当前时刻的输入窗口。
- (X_t^{\mathrm{tr}})：趋势窗口。
- (X_t^{\mathrm{res}})：残差窗口。
- (p)：数值 patch 的索引。

### 3.3 SAGE 符号

- (f_t^b)：第 (b) 个结构表示分支在时刻或窗口 (t) 的特征。
- (c_b)：第 (b) 个结构表示分支的正常特征中心。
- (\rho_b)：第 (b) 个结构表示分支的正常边界或尺度。
- (s_t^{\mathrm{str}})：结构证据异常分数。
- (s_t^{\mathrm{pred}})：预测残差证据异常分数。
- (r_t^{\mathrm{pred}})：SAGE 预测分支的预测残差。
- (g_t)：样本级门控权重，表示预测证据在最终融合中的权重。
- (s_t^{\mathrm{SAGE}})：SAGE 的最终异常分数。

推荐的 SAGE 核心表达为：

\[
s_t^{\mathrm{SAGE}}=(1-g_t)s_t^{\mathrm{str}}+g_t s_t^{\mathrm{pred}}.
\]

其中 (g_t\in[0,1])。门控输入可以由结构特征、预测残差特征和质量统计量组成，但正文只保留其功能定义，逐层网络细节放入实现说明或附录。

### 3.4 TETRA 符号

- (a_i)：第 (i) 条外生文本记录。
- (\tau_i^{\mathrm{pub}})：文本记录 (a_i) 的发布时间。
- (h_i)：冻结文本编码器输出的语义表示。
- (e_i)：事件级文本表示，包含语义信息和必要的事件属性。
- (\mathcal A_p)：对第 (p) 个数值 patch 可用的事件集合。
- (u_p)：第 (p) 个 patch 聚合后的事件表示。
- (X_p^{\mathrm{mask}})：用于数值正常性分支的固定掩码输入。
- (\hat{x}_p)：数值正常性分支对目标 patch 的正常重构。
- (r_p^{\mathrm{rec}})：TETRA 目标 patch 与正常重构之间的重构残差。
- (\mu_p)：事件条件残差的预测均值。
- (\sigma_p)：事件条件残差的不确定性尺度。
- (s_p^{\mathrm{num}})：由数值重构残差得到的异常分数。
- (s_p^{\mathrm{event}})：事件条件残差不一致分数。
- (s_p^{\mathrm{TETRA}})：TETRA 的最终异常分数。

推荐的 TETRA 核心表达为：

\[
\mathcal A_p=\{a_i\mid \tau_i^{\mathrm{pub}}\leq \tau_p\},
\]

\[
(\mu_p,\sigma_p)=g_{\mathrm{event}}(u_p,h_p),
\]

\[
s_p^{\mathrm{event}}=
\frac{(r_p^{\mathrm{rec}}-\mu_p)^2}{\sigma_p^2+\varepsilon},
\]

\[
s_p^{\mathrm{TETRA}}=
\operatorname{Norm}(s_p^{\mathrm{num}})+
\lambda q_p\operatorname{Norm}(s_p^{\mathrm{event}}).
\]

其中 (r_p^{\mathrm{rec}}=x_p-\hat{x}_p) 是数值正常性分支的重构残差，(q_p) 是文本有效性、时间匹配和事件置信度形成的质量权重，\(\lambda\) 由验证集确定。数值分支采用固定掩码协议，训练和推理保持一致。若某个 patch 没有可用事件，则使用预先定义的无事件表示，并令质量权重反映该状态。TETRA 的数值分支在当前设计中采用正常重构，不写成未来预测。

### 3.5 分数、损失和超参数

- 全文统一用小写 (s) 表示异常分数，不在章节间混用 (S) 和 (s)。
- \(\mathcal L\) 只表示训练损失，\(\mathcal L_{\mathrm{SAGE}}\) 和 \(\mathcal L_{\mathrm{TETRA}}\) 分别表示两个模型的总损失。
- \(\lambda\) 表示损失项或分数融合项的权重；同一公式体系中应通过下标区分不同用途，如 \(\lambda_{\mathrm{event}}\)、\(\lambda_{\mathrm{reg}}\)。
- \(\varepsilon\) 只用于数值稳定性，不承担模型权重含义。
- \(\operatorname{Norm}(\cdot)\) 表示在验证集确定统计量后的分数归一化，不能使用测试集统计量。

### 3.6 跨章节概念约束

- SAGE 使用 (r_t^{\mathrm{pred}}) 表示短期预测残差；TETRA 使用 (r_p^{\mathrm{rec}}) 表示固定掩码正常重构残差，二者不能简写成同一个未加上标的 (r)。
- SAGE 讨论内部数值正常性；TETRA 讨论外部事件条件正常性，两个概念需要分别定义。
- (q_p) 表示可观测的文本质量或可用性，\(\sigma_p\) 表示条件残差预测的不确定性，两者承担不同功能。
- 无新闻 patch 可以使用 (e_{\varnothing})，但应同时通过 (q_p) 降低文本分数的影响，避免无事件表示产生虚假文本证据。
- TETRA 需要检查事件分数与数值分数的相关性和增量收益，防止事件一致性分数退化为数值残差分数的重复计算。

## 4. 公式简洁性规则

### 4.1 正文只保留解释方法所需的公式

正文优先保留以下公式：

1. 输入与趋势—残差分解；
2. 两类证据的异常分数；
3. 门控融合；
4. 事件的时间可用性对齐；
5. 事件条件残差预测；
6. 事件不一致性和最终异常分数；
7. 总体训练目标。

### 4.2 不在主线中堆叠实现细节

GAF、DE、MTF、STFT 等具体变换的展开式、逐层 MLP 矩阵、激活函数的逐项展开、伪异常的采样过程和工程缓存细节不应打断方法主线。它们可在实现细节、附录或实验设置中说明。

### 4.3 每个公式只承担一个主要作用

一个公式用于定义对象，一个公式用于说明计算，一个公式用于说明训练或评分。不要把输入、网络、损失和异常分数全部压缩到同一个长公式中。首次出现的符号必须在公式前后立即解释。

### 4.4 先定义对象，再写关系

介绍一个模块时遵循：

```text
输入是什么 → 输出是什么 → 输出如何使用 → 为什么有必要
```

不得先给出包含多个未定义字母的公式，再在数段之后补充符号说明。

## 5. 第二章的内容边界

第二章负责建立概念、问题定义和方法基础，不负责提前写 SAGE 或 TETRA 的完整实现。

第二章的最终小节采用“必要时拆分”的原则：2.2、2.3 和 2.4 设置并列二级小节，2.1、2.5、2.6 和 2.7 采用连续论述，不因目录形式强行增加标题。完整目录见《第一二章最终框架与评审说明》。

### 5.1 第二章应当阐述

- 时序异常检测的基本任务和训练设定；
- 预测、重构和表示学习三类常见检测思路；
- 数值序列中的结构证据与预测残差证据；
- 多源证据存在尺度差异、可靠性差异和互补性的原因；
- 自适应证据融合的基本思想；
- 外生文本、事件信息和时间可用性；
- 上下文感知正常模式与条件正常性的概念；
- 本论文统一的问题定义、数据划分和评价指标。

第二章可以给出通用的异常检测定义，例如正常样本上的训练目标和异常分数的一般形式，但不得使用 SAGE 或 TETRA 的专属符号体系来展开专属模块。

### 5.2 第二章不应展开

- SAGE 的具体结构分支、门控网络和训练流程；
- TETRA 的事件级表示、事件聚合和条件残差头；
- 两个模型的完整损失函数和最终评分公式；
- 针对具体数据集的实验结果；
- 只有在第三、四章才能证明的创新性结论。

第二章的作用是回答“问题是什么、已有方法如何处理、为什么需要新的建模视角”，而不是回答“本文模型每一层如何实现”。

## 6. 第三章与第四章的公式边界

### 6.1 第三章：SAGE

第三章只围绕内部数值证据展开，公式顺序固定为：

```text
输入窗口与分解
→ 结构证据
→ 预测残差证据
→ 样本级门控
→ 训练目标
→ 最终异常分数
```

第三章不引入新闻、事件、发布时间、文本编码或事件条件残差等符号。

### 6.2 第四章：TETRA

第四章只围绕外部事件条件下的数值解释展开，公式顺序固定为：

```text
文本记录与事件表示
→ 时间可用性对齐
→ patch 级事件聚合
→ 条件残差预测
→ 事件不一致性评分
→ 数值分数与事件分数融合
```

第四章可以复用数值主干输出的残差，但必须明确该残差来自数值分支，不重新定义一套同名变量。

## 7. 图表与公式的配套原则

每个核心公式至少对应一个可验证对象：

- 门控公式对应门控分布、固定融合对照和分支消融；
- 时间对齐公式对应时间置换、未来文本屏蔽和零文本对照；
- 条件残差公式对应残差预测误差和事件一致性分数分析；
- 最终融合公式对应权重敏感性和整体指标比较。

图中使用的符号必须与正文一致。实验表格中的“结构分支”“预测分支”“事件分支”和“最终分数”也必须分别对应上述定义，不能用含义模糊的“模块 A”“模块 B”。

## 8. 写作执行检查表

每次新增或修改公式后，检查以下事项：

- 是否复用了已有字母却改变了含义；
- 是否在公式首次出现前定义了所有符号；
- 是否把背景知识误放入方法章节；
- 是否把方法创新提前写入第二章；
- 是否有一个公式同时承担过多功能；
- 是否能通过一个消融或对照实验验证公式的作用；
- 是否使用验证集而非测试集确定归一化统计量和融合权重；
- 是否保持 SAGE 与 TETRA 的符号边界清晰。

后续论文正文、图注、表注和实验记录均按本规范执行。如确需调整符号，应在全文范围内同步修改，并在实验日志中记录变更原因。
