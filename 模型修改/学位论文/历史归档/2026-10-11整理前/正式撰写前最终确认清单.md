## 3. SAGE 定义

- [x] 默认结构表示固定为 GASF，趋势和残差窗口分别进入两个 ViT 一类正常性分支；
- [x] 默认预测骨干固定为 iTransformer，CNN 作为替代骨干消融；
- [x] 门控输入固定为两个归一化分数、分数差异、绝对差异和三个窗口统计量组成的七维特征；
- [x] 伪异常训练方案固定为六类局部扰动加相对敏感度门控目标；
- [x] 参考 PDF 的分解、GASF、双 ViT、robust scaling、共享 MLP 和 Stage 2 训练路径已纳入适配规范；
- [x] 默认预测骨干改为 iTransformer，CNN 仅作为预测骨干对照；
- [x] 正文表述、符号体系和实验结果不直接复用参考 PDF 的名称、数值和结论；
- [ ] 固定平均、验证集固定权重和自适应门控对照固定；
- [ ] 当前主实验随机种子固定为 `2021`、`4396`，若扩展到五个种子需全文同步。

第三章的参考实现映射、适配性调整和正式写作表述见《第三章SAGE参考PDF适配实施规范》。

## 4. TETRA 定义

- [x] 数值分支固定采用端部目标 patch 的掩码正常重构；
- [x] 训练和推理均使用端部固定 mask，数值骨干采用 iTransformer 重构模式；
- [x] 主模型使用冻结文本编码器的有效 token 平均池化，不依赖人工事件属性标注；
- [x] 文本表示粒度固定为事件级，窗口级文本作为对照协议；
- [x] 无新闻表示固定为可学习的 (e_{\varnothing})，但无新闻时令 (q_p=0)；
- [x] (q_p) 固定由事件覆盖率和最近事件时间距离构成；
- [x] 主模型输出 (\mu_p) 和 (\sigma_p)，均值-only 与固定方差作为消融；
- [x] 文本编码器冻结并离线缓存，条件残差阶段只训练轻量文本投影、聚合层和残差头。

## 8. 结论边界

### SAGE

可以表述为：

> 结构证据与预测残差证据具有互补性，自适应融合能够提高整体检测稳健性。

只有固定融合对照稳定成立后，才能进一步强调样本级门控的独立收益。

### TETRA

可以表述为：

> 时间可用的事件文本能够帮助估计外部事件条件下的正常残差，实际残差与条件残差的不一致性可以提供辅助异常证据。

避免使用“发现异常原因”“证明事件导致异常”和“实现因果解释”等超出实验范围的表述。
