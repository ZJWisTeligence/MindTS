# 大论文写作统一规则

更新时间：2026-10-10

本文档记录大论文正式撰写前已经确定的六项统一规则。后续正文、图表、公式和实验报告均按本文档执行。

## 一、总主线

论文总主线确定为：

> **时序异常具有多源异质证据。本文先建模数值序列内部的结构证据与预测残差证据，再引入外部事件信息，判断实际变化是否符合事件条件下的正常模式。**

两个研究工作的关系固定为：

```text
SAGE：内部数值证据的自适应融合
        ↓
TETRA：外部事件条件下的残差对齐
        ↓
多源证据下的时序异常检测
```

SAGE 回答：

> 数值序列内部应该相信哪些异常证据？

TETRA 回答：

> 外部事件能否解释当前数值变化？

论文统一的判断原则为：

> 异常程度是实际行为偏离当前可用证据下预期行为的程度。

## 二、统一术语

| 概念 | 统一术语 |
|---|---|
| 总任务 | 时序异常检测 |
| 数值自身的信息 | 内部时序证据 |
| 新闻、事件文本 | 外部事件证据 |
| 文本模态 | 外生文本 |
| 趋势、局部波动、预测误差、窗口结构 | 内部异常证据 |
| 随上下文变化的正常模式 | 上下文感知正常模式 |
| 理论概括 | 条件正常性 |
| 单条新闻表示 | 事件级文本表示 |
| 新闻是否已经能够使用 | 时间可用性 |
| 新闻与数值 patch 的关系 | 时间可用性对齐 |
| 数值模型没有解释的部分 | 数值残差 |
| 文本预测的正常变化 | 事件条件残差 |
| 实际残差与事件预测的差异 | 事件残差不一致 |
| SAGE 的融合机制 | 样本级自适应门控 |
| 最终结果 | 最终异常分数 |

统一规定：

- 不使用“因果对齐”；
- 不使用“文本直接重构数值”；
- 不把新闻是否存在直接称为事件是否发生；
- “条件正常性”第一次出现时解释为“上下文感知正常模式”；
- 一般叙述优先使用“外部事件证据”，涉及具体输入时使用“外生文本”。

## 三、统一符号

### 3.1 通用符号

| 符号 | 含义 |
|---|---|
| (X) | 输入数值序列或窗口 |
| (X_p) | 第 (p) 个数值 patch |
| (M) | 数值 mask |
| (z_p) | 第 (p) 个数值 patch 表示 |
| (hat X^{num}) | 数值正常性分支的重构结果 |
| (R) | 实际数值残差 |
| (p) | 数值 patch 索引 |
| (t) | 时间索引 |
| (i) | 事件或新闻索引 |

### 3.2 SAGE 符号

| 符号 | 含义 |
|---|---|
| (S^{str}) | 结构证据异常分数 |
| (S^{pred}) | 预测残差异常分数 |
| (g_p) | 第 (p) 个样本的门控权重 |
| (S^{SAGE}) | SAGE 最终异常分数 |

### 3.3 TETRA 符号

| 符号 | 含义 |
|---|---|
| (a_i) | 第 (i) 条外生文本 |
| (	au_i^{pub}) | 第 (i) 条文本的发布时间 |
| (h_i) | 冻结语言模型输出的文本表示 |
| (e_i) | 事件级文本表示 |
| (mathcal A_p) | 第 (p) 个 patch 可用的事件集合 |
| (u_p) | 第 (p) 个 patch 的事件聚合表示 |
| (mu_p) | 事件条件残差均值 |
| (sigma_p) | 事件条件残差不确定性 |
| (S^{num}) | 数值异常分数 |
| (S^{event}) | 事件残差不一致分数 |
| (S^{TETRA}) | TETRA 最终异常分数 |

统一使用 (S^{event})，不在不同章节交替使用 `text score`、`consistency score` 等名称。

## 四、统一章节模板

第三章和第四章采用相同的写作结构：

1. 研究动机；
2. 问题定义；
3. 总体架构；
4. 核心模块；
5. 训练目标；
6. 异常评分；
7. 实验设置；
8. 实验结果与机制分析；
9. 本章小结。

其中：

- 第三章的核心模块是结构分支、预测分支和自适应门控；
- 第四章的核心模块是事件表示、时间对齐、条件残差预测和事件一致性评分。

每个方法章节都按照以下顺序展开：

```text
问题
→ 研究缺口
→ 方法
→ 实验
→ 研究发现
→ 下一章研究动机
```

## 五、统一实验报告规则

### 5.1 数据协议

- 按时间顺序划分训练、验证和测试数据；
- 模型训练只使用正常训练数据；
- 验证集用于早停、超参数和融合权重选择；
- 测试集只进行最终报告；
- 归一化统计量不能使用测试数据；
- TETRA 只能使用检测时刻已经发布的文本。

### 5.2 随机性

最终主实验固定记录随机种子：

```text
2021
4396
```

所有主结果报告两个种子的均值和标准差，不使用最优单次结果代替平均结果。

### 5.3 评价指标

统一报告：

- AUC-PR；
- AUC-ROC；
- VUS-PR；
- VUS-ROC；
- PA-F1。

同时保留数据集级结果，不能只报告平均值。

### 5.4 SAGE 对照实验

- 结构分支；
- 预测分支；
- 固定融合；
- 自适应门控；
- 去除趋势—残差分解；
- 不同结构表示；
- 多随机种子结果。

### 5.5 TETRA 对照实验

- 数值-only；
- 零文本；
- 随机文本；
- 时间置换文本；
- 窗口级文本；
- 事件级文本；
- 仅文本元信息；
- 真实文本。

同时报告：

- 条件残差预测误差；
- 有新闻与无新闻窗口结果；
- 文本有效率；
- 文本特征方差；
- 有效秩；
- 事件权重或质量权重分布。

### 5.6 结果表述

- 使用“在当前数据和实验设置下表现更好”；
- 不写“对所有数据集都有效”；
- 不写“证明了因果关系”；
- 不隐藏不显著或负向结果；
- 不把单次结果描述成稳定收益。

## 六、贡献边界

论文最终只保留三项主要贡献。

### 6.1 SAGE 贡献

> 提出样本级自适应门控证据模型，融合数值序列内部的结构证据与预测残差证据，提高不同异常形态下的检测稳定性。

### 6.2 TETRA 贡献

> 提出时序外生文本残差对齐模型，将外部事件表示为时间可用的事件级文本信息，并预测事件条件下的正常残差，通过残差不一致性识别无法被事件解释的变化。

### 6.3 综合实验贡献

> 建立多源证据下的系统实验体系，验证不同证据来源的互补作用及其适用范围。

以下内容不单独包装成新的主要贡献：

- 使用某个具体语言模型；
- 使用某种具体图像编码器；
- 普通注意力层或投影层；
- 单个工程优化；
- 单一数据集上的局部提升。

## 七、执行规则

从本规则确定后：

- 正文统一使用 SAGE 和 TETRA；
- 两个模型采用不同数值分支时，按任务目标解释，不强行统一网络结构；
- 章节中不随意增加未确定的新模块；
- 实验结果按固定协议记录；
- 术语、公式和图表命名保持一致；
- 任何新增贡献必须先判断是否会破坏论文总主线。
